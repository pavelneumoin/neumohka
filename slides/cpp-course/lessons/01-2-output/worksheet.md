## 1 · Что увидит прохожий

Робот печатает вывеску. Напиши, **что появится на экране** (не забудь про `\n`).

```cpp
std::cout << "ПИЦЦЕРИЯ\n";
std::cout << "Открыто!\n";
std::cout << "Заходи";
```

<div class="lines"></div>

## 2 · Расставь переносы

Робот напечатал всё в одну строку. Перепиши код так, чтобы каждое слово было **на своей строке** — добавь `\n`.

```cpp
std::cout << "РакетаСтартГотов";
```
