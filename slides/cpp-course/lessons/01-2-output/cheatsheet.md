## Несколько строк

Каждая команда `std::cout` печатает свой кусочек:

```cpp
std::cout << "Первая строка\n";
std::cout << "Вторая строка\n";
```

## Перенос строки

Робот сам не переходит на новую строку — прикажи ему:

```cpp
std::cout << "Текст" << std::endl;  // способ 1
std::cout << "Текст\n";             // способ 2 (короче)
```

## Секретные символы 🔑

| Символ | Что делает |
|---|---|
| `\n` | перенос на новую строку |
| `\t` | отступ-«столбик» (табуляция) |
| `\\` | напечатать сам `\` |
| `\"` | кавычка внутри текста |

## Картинка из символов

```cpp
std::cout << "  *  \n";
std::cout << " *** \n";
std::cout << "*****\n";
```

## Запомни ✅

- Все секретные символы начинаются с `\`
- `\n` ставим **внутри** кавычек, в конце текста
- Хочешь рисунок — каждая строчка это отдельный `std::cout`
