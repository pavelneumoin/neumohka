## Пять операторов

| Оператор | Что делает | Пример |
|---|---|---|
| `+` | сложение | `60 + 35` → `95` |
| `-` | вычитание | `100 - 95` → `5` |
| `*` | умножение | `60 * 3` → `180` |
| `/` | деление | `100 / 4` → `25` |
| `%` | остаток | `10 % 3` → `1` |

## Касса считает заказ

```cpp
int total = price * count;   // стоимость
int change = paid - total;   // сдача
```

## Порядок действий

```cpp
int a = 2 + 3 * 4;     // = 14 (сначала *)
int b = (2 + 3) * 4;   // = 20 (скобки первыми)
```

Сначала `*` и `/`, потом `+` и `-`. Скобки `( )` считаются первыми.

## Деление: int против double

```cpp
int a = 7 / 2;        // 3  — дробь отброшена!
double b = 7.0 / 2;   // 3.5 — точно
```

## Запомни ✅

- `int / int` отбрасывает дробь — для копеек бери `double`
- Хотя бы одно число с точкой → деление точное
- `%` даёт остаток от деления
- На ноль делить нельзя

## Частые ошибки ⚠️

| Ошибка | Как правильно |
|---|---|
| `5 / 2` ждали `2.5` | `5.0 / 2` → `2.5` |
| `2 + 3 * 4` ждали `20` | `(2 + 3) * 4` → `20` |

## Словарик 📖

- **Оператор** — знак действия: `+ - * / %`
- **Остаток** (`%`) — что не поделилось нацело
- **Порядок действий** — что считается раньше
