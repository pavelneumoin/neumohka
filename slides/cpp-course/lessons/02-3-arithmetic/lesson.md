## Пять операторов кассы 🧮

| Оператор | Что делает | Пример |
|---|---|---|
| `+` | сложение | `60 + 35` → `95` |
| `-` | вычитание | `100 - 95` → `5` |
| `*` | умножение | `60 * 3` → `180` |
| `/` | деление | `100 / 4` → `25` |
| `%` | остаток | `100 % 30` → `10` |

<div class="fact">С этими пятью значками я посчитаю что угодно: сумму чека, сдачу, скидку. В играх так же считают очки и монеты!</div>

## Считаем стоимость заказа

```cpp
int price = 60;
int count = 3;
int total = price * count;
std::cout << "Итого: " << total << " руб.\n";
```

### Цену умножаю на количество — получаю стоимость.

<div class="fact">На экране: <span class="out">Итого: 180 руб.</span> Результат <strong>price * count</strong> я положил в новый ящик <strong>total</strong>.</div>

---

## Считаем сдачу

```cpp
int total = 180;
int paid = 200;
int change = paid - total;
std::cout << "Сдача: " << change << " руб.\n";
```

### Из денег покупателя вычитаю стоимость — это сдача.

<div class="fact">На экране: <span class="out">Сдача: 20 руб.</span> Я считаю сдачу сам — кассиру даже думать не надо!</div>

## Порядок действий

### Как в математике: сначала `*` и `/`, потом `+` и `-`.

```cpp
int sum = 2 + 3 * 4;   // сначала 3*4, потом +2
```

<div class="bubble"><img class="bip-head" src="../../assets/bip-head.svg"><span>Получится 14, а не 20! Умножение «сильнее» сложения — я всегда делаю его первым.</span></div>

---

## Скобки меняют порядок

```cpp
int a = 2 + 3 * 4;     // = 14
int b = (2 + 3) * 4;   // = 20
```

### Скобки `( )` выполняются первыми — как в обычной математике.

<div class="tip">Хочешь, чтобы я сначала сложил — поставь <strong>скобки</strong>. То, что в них, я посчитаю в первую очередь.</div>

---

## Хитрость деления целых

```cpp
int a = 7 / 2;
std::cout << a;
```

### Внимание: получится `3`, а не `3.5`!

<div class="fact">Когда я делю `int` на `int`, дробную часть я <strong>отбрасываю</strong>. Касса теряет копейки! На экране будет <span class="out">3</span></div>

---

## Чтобы делить точно — нужен double

```cpp
double a = 7.0 / 2;
std::cout << a;
```

### Хотя бы одно число с точкой — и деление станет точным.

<div class="fact">Теперь получится <span class="out">3.5</span> — точно! Для денег с копейками всегда бери `double`.</div>

---

## Остаток от деления: оператор %

```cpp
int apples = 10;
int boxes = apples / 3;   // 3 коробки
int left = apples % 3;    // 1 яблоко осталось
```

### `%` показывает остаток — то, что не поместилось.

<div class="fact">10 яблок по 3 в коробку: 3 полные коробки и 1 яблоко в остатке. Так же проверяют, чётное число или нет!</div>

---

## Касса считает в два шага

```cpp
int price = 50;
int count = 4;
int total = price * count;   // 200
int change = 250 - total;    // 50
```

### Стоимость заказа — `200`, сдача с `250` руб. — `50`.

<div class="bubble"><img class="bip-head" src="../../assets/bip-head.svg"><span>Сначала умножил, потом вычел — два шага, и готово. Видишь, я и правда касса!</span></div>
