## Собираем по одному шагу

### Берём первый шаг плана, пишем, запускаем — и только потом следующий.

```cpp
// Шаг 1: поздороваться
std::cout << "Игра-викторина! Готов?\n";
// запустили — работает? отлично, пишем шаг 2
```

<div class="tip">Не пиши сразу всё. Каждый рабочий шаг — это <strong>+1 к уверенности</strong>. Маленькие победы складываются в большой проект.</div>

## Два вида ошибок

<div class="cols">

<div>

**Ошибка компилятора**
программа **не запускается**: забыл `;`, кавычку, скобку

</div>

<div>

**Ошибка логики**
программа запускается, но **считает неправильно**

</div>

</div>

<div class="tip">Первую покажет g++ красным текстом — он сам подскажет строку. Вторую ищем сами: глазами и проверкой.</div>

---

## Как читать ошибку компилятора

```cpp
std::cout << "Привет"     // забыли ;
std::cout << "Пока";
```

### g++ напишет что-то вроде: `error: expected ';' before 'std'`

<div class="tip">Главное — <strong>номер строки</strong> в ошибке. Смотри на эту строку и строку <strong>над</strong> ней: часто пропущенный знак прячется именно там.</div>

---

## Где искать ошибку логики

```cpp
int score = 0;
if (answer == "Париж") score = 1;   // а не score + 1!
std::cout << "Очков: " << score;    // всегда 1?
```

### Программа работает, но считает не так. Проверь её «руками».

<div class="fact">Ответил правильно дважды, а очков всё равно 1? Значит, нашёл ошибку логики. Программа честно делает то, что написано — просто написано не то.</div>

---

## Метод «печатаем подсказки» 🔍

### Не знаешь, что внутри переменной? Выведи её!

```cpp
std::cout << "[отладка] score = " << score << "\n";
```

<div class="try">Вставь временный `std::cout` прямо сейчас в свой проект и посмотри, какое значение на самом деле. Нашёл ошибку — убрал подсказку.</div>

## Частые проблемы и решения ⚠️

<div class="grid">

<div class="card">
<span class="ico">⚠️</span>

### `error: expected ';'`
Забыл точку с запятой. Добавь `;` в конце строки.

</div>

<div class="card">
<span class="ico">⚠️</span>

### Окно сразу закрылось
Так и должно быть — это не ошибка. Запускай из терминала.

</div>

<div class="card">
<span class="ico">⚠️</span>

### `cin` не читает строку
Имя из двух слов? Используй `std::getline`.

</div>

<div class="card">
<span class="ico">⚠️</span>

### Считает неправильно
Проверь `=` против `==` и `score = score + 1`.

</div>

</div>

## `getline` для длинного ответа

### `std::cin >>` читает одно слово. Для целой фразы — `std::getline`.

```cpp
std::string name;
std::cout << "Как тебя зовут? ";
std::getline(std::cin, name);
std::cout << "Привет, " << name << "!";
```

### Удобно, когда ответ из нескольких слов: «Нижний Новгород».

---

## Советы от опытных 🧠

- Запускай **часто** — после каждого маленького шага
- Имена переменных — понятные: `score`, а не `s`
- Сломалось? Вспомни, **что менял** последним
- Не получается час — спроси или отложи, отдохни
- Сохраняй рабочую версию перед большими правками
