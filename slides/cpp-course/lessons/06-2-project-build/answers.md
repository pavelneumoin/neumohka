## 2 · Какая это ошибка?

<div class="solution">Забыл точку с запятой — <strong>К</strong> (компилятор, не запускается). Очки всегда = 1 — <strong>Л</strong> (логика: запускается, но считает неверно). Не хватает закрывающей скобки — <strong>К</strong> (компилятор). Главная мысль: ошибка компилятора мешает запуску, ошибка логики прячется в работающей программе.</div>

## 3 · Почини код

Три ошибки: нет `;` после `score = 0`; переменная `answer` не объявлена; нет `#include` и `int answer`. Исправленный вариант:

```cpp
#include <iostream>

int main() {
    int score = 0;
    int answer = 0;
    std::cout << "Вопрос: 2 + 2?";
    std::cin >> answer;
    return 0;
}
```

<div class="solution">Три исправления: 1) поставить точку с запятой после нуля; 2) объявить answer до cin (int answer = 0;); 3) добавить include iostream, чтобы работали cout и cin. Если ученик нашёл только две — засчитываем, но показываем третью.</div>

## 4 · Следующий шаг проекта

Образец следующего шага — добавить второй вопрос и общий счётчик:

```cpp
#include <iostream>

int main() {
    int score = 0;
    int answer = 0;

    std::cout << "Сколько будет 3 + 5? ";
    std::cin >> answer;
    if (answer == 8) {
        score = score + 1;
    }

    std::cout << "Сколько будет 10 - 4? ";
    std::cin >> answer;
    if (answer == 6) {
        score = score + 1;
    }

    std::cout << "Всего очков: " << score << "\n";
    return 0;
}
```

<div class="solution">Принимается любой осмысленный следующий шаг (новый вопрос, выбор пути, новый счётчик). Важно: код компилируется и продолжает прошлый шаг, а не начинает заново.</div>

## 5 · Отладка подсказкой

Образец отладочной печати — показать значение переменной после ввода:

```cpp
std::cin >> answer;
std::cout << "[отладка] answer = " << answer << "\n";
```

<div class="solution">Критерий: cout стоит сразу после места, где переменная меняется, и печатает её имя и значение. Хорошо, если ученик понимает, что эту строку потом убирают.</div>
