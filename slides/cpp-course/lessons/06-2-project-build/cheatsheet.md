## Порядок сборки 📋

1. Возьми **один** шаг из плана
2. Напиши код этого шага
3. Запусти и проверь
4. Работает — сохрани (чекпоинт 💾)
5. Берись за следующий шаг

## Два вида ошибок

- **Компилятор** — не запускается: `;`, кавычки, скобки
- **Логика** — запускается, но считает неверно

## Отладка подсказками 🔍

```cpp
std::cout << "[отладка] score = " << score << "\n";
```

Вставь временный вывод → посмотри значение → найди ошибку → убери.

## Частые проблемы

| Проблема | Решение |
|---|---|
| `expected ';'` | добавь `;` в конце строки |
| ответ из 2 слов не читается | `std::getline(std::cin, x)` |
| `score` всегда 1 | пиши `score = score + 1` |
| перепутал `=` и `==` | в условии — `==` |

## Прочитать целую фразу

```cpp
std::string name;
std::getline(std::cin, name);
```

## Запомни ✅

- Запускай **часто** — после каждого шага
- Сломалось? Вспомни, что менял последним
- Имена переменных — понятные: `score`, не `s`

## Словарик 📖

- **Чекпоинт** — рабочая версия, точка сохранения
- **Отладка** — поиск и починка ошибок
