## Твоя первая программа

```cpp
#include <iostream>

int main() {
    std::cout << "Привет! Я твой робот.";
    return 0;
}
```

## Разберём по строчкам

```cpp
#include <iostream>   // даёшь мне «рот»
int main() {          // отсюда я стартую
    std::cout << "Привет!";  // приказ: скажи это
    return 0;         // всё хорошо, конец
}
```

### Дальше разберём каждую строчку отдельно.

---

## Строчка 1 · `#include <iostream>`

### Это «коробка с инструментами» для ввода и вывода.

<div class="fact"><strong>iostream</strong> = input/output stream, «поток ввода-вывода». Без него я не умею ни говорить, ни слушать.</div>

---

## Строчка 2 · `int main()`

### Главная функция — точка, с которой я стартую.

<div class="bubble"><img class="bip-head" src="../../assets/bip-head.svg"><span>Что бы ты ни написал, я всегда начинаю с main. Весь код урока живёт внутри фигурных скобок { }.</span></div>

---

## Строчка 3 · `std::cout << "..."`

### Команда «скажи вслух». Стрелочки `<<` показывают, что вывести.

```cpp
std::cout << "Любой текст в кавычках";
```

<div class="try">Поменяй текст в кавычках на своё имя — я назовусь твоим именем.</div>

---

## Два железных правила

<div class="tip">Текст для вывода — всегда в <strong>кавычках</strong> «…». А в конце каждой команды — <strong>точка с запятой</strong> ;</div>

### Забудешь одно из них — я не пойму и покажу ошибку.

---

## Две главные ошибки новичка

<div class="grid">

<div class="card">

<div class="card">

## Проверь себя 🧠

### Что я выведу на экран?

```cpp
std::cout << "5 + 3";
```

<div class="fact">Я выведу <span class="out">5 + 3</span> — как текст! В кавычках всё считается обычными буквами, а не числами. Считать научимся позже.</div>

# Задача 2 · Робот знакомится 👋

Пусть твой робот в **двух строках** расскажет о себе:

```cpp
std::cout << "Меня зовут Бип.\n";
std::cout << "Я умею считать!";
```

<div class="tip">Каждая новая строка — это ещё один <strong>std::cout</strong>. Добавь третью: что робот любит.</div>
