## 1 · Кто за что отвечает

Соедини строку программы с тем, что она делает (впиши букву справа).

| Строка | | Что делает |
|---|---|---|
| `#include <iostream>` | ___ | **А** — печатает текст на экран |
| `int main()` | ___ | **Б** — даёт роботу «рот», чтобы говорить |
| `std::cout << "Привет!";` | ___ | **В** — отсюда робот начинает работу |

## 2 · Робот сломался — почини его 🔧

В коде робота **две ошибки**. Найди и обведи их, а рядом напиши исправленную строку.

```cpp
int main() {
    std::cout << Доброе утро!;
    return 0
}
```
