## Каркас программы

Любая программа на C++ начинается так:

```cpp
#include <iostream>

int main() {
    // сюда пишем команды
    return 0;
}
```

## Сказать что-то вслух

```cpp
std::cout << "Привет!";
```

`std::cout <<` = «вывести на экран». Текст — всегда в кавычках `" "`.

## Запомни 3 правила ✅

- Команды робот выполняет **сверху вниз**, по одной
- Текст пишем в **кавычках** `"..."`
- В конце каждой команды — **точка с запятой** `;`

## Частые ошибки ⚠️

| Ошибка | Как правильно |
|---|---|
| `std::cout << Привет;` | `std::cout << "Привет";` |
| `std::cout << "Привет"` | `std::cout << "Привет";` |

## Словарик 📖

- **Компилятор** — переводит твой код на язык робота
- **`main`** — главная функция, с неё начинается программа
- **`std::cout`** — «рот» робота, печатает текст на экран
