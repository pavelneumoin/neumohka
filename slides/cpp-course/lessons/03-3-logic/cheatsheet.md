# Собираем викторину 🎮
</div>

## `&&` — «И» (нужны оба)

```cpp
if (coins >= 100 && level >= 3) {
    std::cout << "Меч куплен";
}
```

Правда, только когда **оба** условия — правда.

## `||` — «ИЛИ» (хватит одного)

```cpp
if (hp == 0 || time == 0) {
    std::cout << "Игра окончена";
}
```

Правда, когда **хотя бы одно** условие — правда.

## `!` — «НЕ» (наоборот)

```cpp
if (!paused) {
    std::cout << "Игра идёт";
}
```

Переворачивает `true` в `false` и обратно.

## Шаги викторины

```cpp
int answer;
std::cout << "2 + 2 = ? ";
std::cin >> answer;
if (answer == 4) {
    std::cout << "Верно!";
}
```

Спросить → прочитать `cin` → проверить `if`.

## Запомни ✅

- Логика — **двойные** знаки: `&&` и `||`
- `&&` — оба, `||` — хотя бы один
- Ответ сравниваем через `==`

## Частые ошибки ⚠️

| Ошибка | Как правильно |
|---|---|
| `a & b` | `a && b` |
| `a \| b` | `a \|\| b` |
| `if (x = 4)` | `if (x == 4)` |

## Словарик 📖

- **`&&`** — логическое «И»
- **`||`** — логическое «ИЛИ»
- **`!`** — логическое «НЕ»
- **викторина** — игра «вопрос → ответ → проверка»
