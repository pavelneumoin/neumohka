## Вспомним прошлый урок

- `if (условие) { }` — выполнить, если правда
- `else` и `else if` — другие ветки
- Условие — это сравнение из урока 3.1

> Сегодня будем **соединять** несколько условий в одно.

---

## План урока

1. `&&` — «И» (оба условия)
2. `||` — «ИЛИ» (хотя бы одно)
3. `!` — «НЕ» (наоборот)
4. Сравниваем введённый ответ
5. **Мини-проект: викторина**
6. **Домашнее задание**

---

## `&&` — нужно, чтобы оба

### `&&` читается «И». Правда только когда **оба** условия — правда.

```cpp
int coins = 120;
int level = 5;
if (coins >= 100 && level >= 3) {
    std::cout << "Можно купить меч!";
}
```

> Монет хватает **И** уровень открыт — обе проверки правда, значит меч доступен.

---

## `||` — достаточно одного

### `||` читается «ИЛИ». Правда, когда **хотя бы одно** условие — правда.

```cpp
int hp = 0;
int time = 50;
if (hp == 0 || time == 0) {
    std::cout << "Игра окончена";
}
```

> Здоровье кончилось **ИЛИ** время вышло — хватит одного, чтобы игра завершилась.

---

## `!` — наоборот

### `!` читается «НЕ» — переворачивает правду в ложь и наоборот.

```cpp
bool paused = false;
if (!paused) {
    std::cout << "Игра идёт";
}
```

> `paused` — `false` (не на паузе). `!paused` превращает это в `true`, поэтому игра идёт.

---

## Таблица «И» и «ИЛИ»

| A | B | `A && B` | `A \|\| B` |
|---|---|---|---|
| true | true | true | true |
| true | false | false | true |
| false | false | false | false |

> `&&` строгий — нужны **оба**. `||` добрый — хватит **одного**.

---

## Worked example · бонус в игре

```cpp
int score = 95;
int lives = 3;
if (score >= 90 && lives > 0) {
    std::cout << "Бонус-уровень открыт!";
} else {
    std::cout << "Бонус закрыт";
}
```

> Очков 95 (≥ 90) **И** жизни есть (3 > 0) — обе правда. Программа откроет бонус-уровень.

---

## Сравниваем ответ игрока

### В викторине мы сравниваем введённое число с правильным ответом.

```cpp
int answer;
std::cin >> answer;
if (answer == 4) {
    std::cout << "Верно!";
} else {
    std::cout << "Неверно";
}
```

> Спросили «2 + 2?». Если игрок ввёл 4 — `answer == 4` правда, печатаем «Верно!».

## Частые ошибки

<div class="grid">

<div class="card">
<span class="ico">⚠️</span>

### Один `&` или `|`
Логика — это `&&` и `||`, **двойные** знаки.

</div>

<div class="card">
<span class="ico">⚠️</span>

### `=` вместо `==`
В условии всегда сравнение `==`, а не присваивание `=`.

</div>

<div class="card">
<span class="ico">⚠️</span>

### Путаем И/ИЛИ
`&&` — нужны оба, `||` — хватит одного. Не перепутай.

</div>

</div>

## Проверь себя · что выведет программа? 🧠

```cpp
int score = 80;
int lives = 0;
std::cout << (score >= 50 && lives > 0);
```

### Подумай 10 секунд…

> Очков хватает (правда), но жизней нет (`0 > 0` — ложь). Для `&&` нужны **оба** — значит результат **0** (false).
