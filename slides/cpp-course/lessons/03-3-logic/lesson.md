## `&&` — нужно, чтобы оба

### `&&` читается «И». Правда только когда **оба** условия — правда.

```cpp
int coins = 120;
int level = 5;
if (coins >= 100 && level >= 3) {
    std::cout << "Можно купить меч!";
}
```

<div class="bubble"><img class="bip-head" src="../../assets/bip-head.svg"><span>Монет хватает <strong>И</strong> уровень открыт — обе проверки правда, значит меч можно купить.</span></div>

---

## `||` — достаточно одного

### `||` читается «ИЛИ». Правда, когда **хотя бы одно** условие — правда.

```cpp
int hp = 0;
int timeLeft = 50;
if (hp == 0 || timeLeft == 0) {
    std::cout << "Игра окончена";
}
```

<div class="fact">Здоровье кончилось ИЛИ время вышло — хватит одного, чтобы игра завершилась. Тут здоровье на нуле, и этого уже достаточно.</div>

---

## `!` — наоборот

### `!` читается «НЕ» — переворачивает правду в ложь и наоборот.

```cpp
bool paused = false;
if (!paused) {
    std::cout << "Игра идёт";
}
```

<div class="bubble"><img class="bip-head" src="../../assets/bip-head.svg"><span>Переменная paused — false, то есть «не на паузе». Знак <strong>!</strong> переворачивает её в true, поэтому игра идёт.</span></div>

---

## Таблица «И» и «ИЛИ»

| A | B | `A && B` | `A \|\| B` |
|---|---|---|---|
| true | true | true | true |
| true | false | false | true |
| false | false | false | false |

<div class="tip">Знак <strong>&amp;&amp;</strong> строгий — нужны оба условия. Знак <strong>||</strong> добрый — хватит одного.</div>

---

## Разбор примера · бонус в игре

```cpp
int score = 95;
int lives = 3;
if (score >= 90 && lives > 0) {
    std::cout << "Бонус-уровень открыт!";
} else {
    std::cout << "Бонус закрыт";
}
```

На экране: <span class="out">Бонус-уровень открыт!</span>

<div class="fact">Очков 95 (это &gt;= 90) И жизни есть (3 &gt; 0) — обе проверки правда, поэтому открывается бонус-уровень.</div>

## Сравниваем ответ игрока

### В викторине мы сравниваем введённое число с правильным ответом.

```cpp
int answer;
std::cin >> answer;
if (answer == 4) {
    std::cout << "Верно!";
} else {
    std::cout << "Неверно";
}
```

<div class="bubble"><img class="bip-head" src="../../assets/bip-head.svg"><span>Спросил «сколько будет 2 + 2?». Игрок ввёл 4, «4 равно 4?» — правда, печатаю «Верно!». Не забудь: тут <strong>==</strong>, а не одиночное =.</span></div>

## Частые ошибки

<div class="grid">

<div class="card">
<span class="ico">⚠️</span>

### Один `&` или `|`
Логика — это `&&` и `||`, **двойные** знаки.

</div>

<div class="card">
<span class="ico">⚠️</span>

### `=` вместо `==`
В условии всегда сравнение `==`, а не присваивание `=`.

</div>

<div class="card">
<span class="ico">⚠️</span>

### Путаем И/ИЛИ
`&&` — нужны оба, `||` — хватит одного. Не перепутай.

</div>

</div>

---

## Проверь себя · что я выведу? 🧠

```cpp
int score = 80;
int lives = 0;
std::cout << (score >= 50 && lives > 0);
```

### Подумай 10 секунд…

<div class="bubble"><img class="bip-head" src="../../assets/bip-head.svg"><span>Очков хватает (правда), но жизней нет («0 &gt; 0» — ложь). Для <strong>&amp;&amp;</strong> нужны оба, значит выведу <span class="out">0</span> — false.</span></div>
