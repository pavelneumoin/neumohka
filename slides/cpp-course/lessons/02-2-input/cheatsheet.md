## Ввод данных

`std::cin` — «уши» программы, читает с клавиатуры:

```cpp
int count;
std::cin >> count;   // стрелки внутрь ящика
```

## Вывод и ввод рядом

| Команда | Что делает | Стрелки |
|---|---|---|
| `std::cout <<` | печатает на экран | наружу `<<` |
| `std::cin >>` | читает с клавиатуры | внутрь `>>` |

## Сначала спроси — потом читай

```cpp
std::string name;
std::cout << "Как вас зовут? ";
std::cin >> name;
std::cout << "Привет, " << name << "!\n";
```

## Запомни ✅

- Сначала **объяви** переменную, потом читай в неё
- Перед `std::cin` печатай **вопрос** через `std::cout`
- `std::cin >>` читает **одно слово** (до пробела)
- Стрелки `>>` всегда смотрят в переменную

## Частые ошибки ⚠️

| Ошибка | Как правильно |
|---|---|
| `std::cin << count;` | `std::cin >> count;` |
| `std::cin >> count;` без `int count;` | сначала `int count;` |
| ввод без вопроса | сперва `std::cout << "...";` |

## Словарик 📖

- **`std::cin`** — ввод данных с клавиатуры
- **Ввод** — данные, которые вводит пользователь
- **`>>`** — стрелки ввода, кладут данные в переменную
