## Зачем мне ввод?

### Я знаю цену из кода. Но не знаю, кто пришёл в магазин.

<div class="bubble"><img class="bip-head" src="../../assets/bip-head.svg"><span>Твоё имя, сколько товаров ты берёшь, твой возраст — всё это знаешь только ты. Я должен <strong>спросить</strong> и запомнить ответ. Для этого у меня есть «уши» — std::cin.</span></div>

---

## Знакомимся с std::cin

```cpp
int count;
std::cin >> count;
```

### Стрелочки `>>` смотрят **в** переменную — туда кладётся ввод.

- `std::cout <<` — стрелочки наружу, **выводим**
- `std::cin >>` — стрелочки внутрь, **вводим**

<div class="fact">Запомни направление так: cout «выплёвывает» текст наружу, а cin «втягивает» ввод внутрь ящика.</div>

---

## Сравни две команды

<div class="cols">

<div>

**Вывод**

```cpp
std::cout << count;
```
показать на экране

</div>

<div>

**Ввод**

```cpp
std::cin >> count;
```
прочитать с клавиатуры

</div>

</div>

<div class="tip">Стрелки всегда указывают, <strong>куда</strong> движутся данные: cout — наружу, на экран; cin — внутрь переменной.</div>

---

## Сначала объяви ящик

```cpp
int count;
std::cin >> count;
```

### Сначала заводим ящик `count`, потом кладём в него ввод.

<div class="bubble"><img class="bip-head" src="../../assets/bip-head.svg"><span>Нельзя класть в ящик, которого нет! Сперва объяви переменную — потом я наполню её тем, что введут.</span></div>

---

## Хороший магазин сначала спрашивает

```cpp
int count;
std::cout << "Сколько товаров берёте? ";
std::cin >> count;
```

### Перед `std::cin` всегда печатаем вопрос — иначе покупатель не поймёт.

<div class="tip">Без подсказки экран просто молчит и мигает курсором. Вежливый магазин сначала <strong>спрашивает</strong>, а потом слушает.</div>

---

## Спросили число — повторили ответ

```cpp
int count;
std::cout << "Сколько яблок? ";
std::cin >> count;
std::cout << "Вы берёте " << count << " шт.\n";
```

### Спросили → покупатель ввёл `5` → я повторил ответ.

<div class="fact">На экране: <strong>Сколько яблок?</strong> покупатель печатает 5, и я отвечаю <span class="out">Вы берёте 5 шт.</span></div>

## Подвох: я читаю одно слово

### `std::cin >>` останавливается на пробеле.

<div class="bubble"><img class="bip-head" src="../../assets/bip-head.svg"><span>Если ввести «Иван Петров», в ящик попадёт только <strong>Иван</strong> — на пробеле я останавливаюсь. Имя и фамилию вместе мы научимся читать позже. Пока — по одному слову.</span></div>

---

## Несколько вводов подряд

```cpp
std::string name;
int count;
std::cin >> name;
std::cin >> count;
```

### Можно спросить несколько вещей — каждую в свою переменную.

<div class="fact">Покупатель вводит ответы по очереди, разделяя их пробелом или клавишей Enter. Я разложу их по нужным ящикам.</div>

## Частые ошибки ⚠️

<div class="grid">

<div class="card">
<span class="ico">⚠️</span>

### Не та стрелка
`std::cin << count;` — у `cin` стрелки `>>`.

</div>

<div class="card">
<span class="ico">⚠️</span>

### Забыл объявить
`std::cin >> count;` без `int count;` выше.

</div>

<div class="card">
<span class="ico">⚠️</span>

### Нет вопроса
Без `cout` экран молчит — покупатель растерян.

</div>

</div>

## Проверь себя · что здесь не так? 🧠

```cpp
int age;
std::cin << age;
```

### Подумай 10 секунд…

<div class="fact">Ошибка в стрелочках! У std::cin они смотрят <strong>внутрь</strong> переменной: std::cin >> age; Стрелки << — только у cout.</div>

Покупатель ввёл число **3**.

```cpp
int count;

```

<div class="fact">Появится <span class="out">Товаров: 3</span> — введённое число попало в ящик count и вывелось обратно.</div>
