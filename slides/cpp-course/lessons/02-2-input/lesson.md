# Программа умеет не только говорить, но и <mark>слушать</mark>.

### Сегодня покупатель сам введёт свои данные — а магазин ответит.

---

## Вспомним прошлый урок

- Переменная — «ящик с именем»: `int price = 50;`
- Типы: `int`, `double`, `std::string`, `char`, `bool`
- Вывод значения: `std::cout << price;` — без кавычек

> Раньше мы сами писали значения в код. Сегодня их введёт **покупатель**.

---

4. Диалог: спросили — ответили
5. **Практика в классе** — магазин общается

---

## Зачем программе ввод?

### Готовый код знает цену. Но не знает, кто пришёл в магазин.

> Имя покупателя, сколько товаров он берёт, его возраст — всё это знает только сам покупатель. Программа должна **спросить** и запомнить ответ.

**`std::cin`** — это «уши» программы: она слушает, что ввели с клавиатуры.

---

## Знакомимся с std::cin

```cpp
int count;
std::cin >> count;
```

### Стрелочки `>>` смотрят **в** переменную — туда кладётся ввод.

- `std::cout <<` — стрелочки наружу, **выводим**
- `std::cin >>` — стрелочки внутрь, **вводим**

---

## Сначала объяви ящик

```cpp
int count;
std::cin >> count;
```

### Сначала заводим ящик `count`, потом кладём в него ввод.

> Нельзя читать в то, чего нет. Сперва объявляем переменную — потом `std::cin` наполняет её.

---

## Хороший магазин сначала спрашивает

```cpp
int count;
std::cout << "Сколько товаров берёте? ";
std::cin >> count;
```

### Перед `std::cin` всегда печатаем вопрос — иначе покупатель не поймёт.

> Без подсказки экран просто молчит и ждёт. Вежливый магазин сначала спрашивает.

---

## Worked example · спросили число

```cpp
int count;
std::cout << "Сколько яблок? ";
std::cin >> count;
std::cout << "Вы берёте " << count << " шт.\n";
```

### Спросили → покупатель ввёл `5` → программа повторила ответ.

> На экране: **Сколько яблок?** `5` → **Вы берёте 5 шт.**

---

## Читаем имя покупателя

```cpp
std::string name;
std::cout << "Как вас зовут? ";
std::cin >> name;
std::cout << "Здравствуйте, " << name << "!\n";
```

### Так же читаем и текст — в переменную типа `std::string`.

> `std::cin >> name` читает **одно слово** до пробела. Для имени этого хватает.

---

## Подвох: cin читает одно слово

### `std::cin >>` останавливается на пробеле.

> Если ввести «Иван Петров», в `name` попадёт только **Иван**. Для имени и фамилии нужен особый приём — его пройдём позже. Сегодня вводим по одному слову.

---

## Несколько вводов подряд

```cpp
std::string name;
int count;
std::cin >> name;
std::cin >> count;
```

### Можно спросить несколько вещей — каждую в свою переменную.

> Покупатель вводит ответы по очереди, разделяя их пробелом или Enter.

---

</div>

</div>

</div>

---

## Проверь себя · что здесь не так? 🧠

```cpp
int age;
std::cin << age;
```

### Подумай 10 секунд…

> Ошибка в стрелочках! У `std::cin` они смотрят **внутрь** переменной: `std::cin >> age;`. Стрелки `<<` — только у `cout`.

---

## Проверь себя · что выведет? 🧠

Покупатель ввёл число **3**.

```cpp
int count;
std::cin >> count;
std::cout << "Товаров: " << count;
```

> Появится **Товаров: 3** — введённое число попало в ящик `count` и вывелось.
