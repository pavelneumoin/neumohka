## `std::string` — строка текста

```cpp
#include <string>

std::string delo = "Сделать уроки";
```

### Строка хранит любой текст: слово, фразу, целое дело.

<div class="tip">Для строк нужен <code>#include &lt;string&gt;</code> вверху программы.</div>

---

## Длина строки: `.length()`

```cpp
std::string delo = "Уроки";
std::cout << delo.length();
```

### `.length()` говорит, **сколько символов** в строке.

<div class="fact">В слове «Уроки» пять букв — выведет <span class="out">5</span>. Пробелы тоже считаются за символы!</div>

---

## Склейка строк: `+`

```cpp
std::string imya = "Аня";
std::cout << "Привет, " + imya + "!";
```

### Плюс `+` **склеивает** строки в одну.

<span class="out">Привет, Аня!</span>

---

## Сравнение строк: `==`

```cpp
std::string otvet = "да";
if (otvet == "да") {
    std::cout << "Поехали!";
}
```

### Две строки сравнивают через `==` — точно так же, как числа.

<div class="tip">Важно: «да» и «Да» — это <strong>разные</strong> строки. Большая буква имеет значение!</div>

---

## Ввод одного слова: `std::cin`

```cpp
std::string slovo;
std::cin >> slovo;
```

### `std::cin >>` читает **одно слово** — до первого пробела.

<div class="fact">Если ввести «Сделать уроки», то в <code>slovo</code> попадёт только «Сделать». Для дел это не годится!</div>

---

## Ввод целой строки: `std::getline`

```cpp
std::string delo;
std::getline(std::cin, delo);
```

### `std::getline` читает **всю строку целиком** — вместе с пробелами.

<div class="bubble"><img class="bip-head" src="../../assets/bip-head.svg"><span>Теперь «Сделать уроки» попадёт ко мне полностью. Вот это нам и нужно для списка дел!</span></div>

---

## Список дел = `vector<string>`

```cpp
#include <vector>
#include <string>

std::vector<std::string> dela;
dela.push_back("Сделать уроки");
dela.push_back("Погулять");
```

### Список строк хранит сразу несколько дел — как журнал оценок, только из текста.

---

### Вводим — складываем — выводим. Так работает любой список дел.

---

## Выводим список дел

```cpp
for (int i = 0; i < dela.size(); i++) {
    std::cout << i + 1 << ". " << dela[i] << "\n";
}
```

### Перебираем список и печатаем дела с номерами.

<div class="tip"><code>i + 1</code> нужно, чтобы нумерация для человека шла с <strong>1</strong>, а не с 0.</div>

## Частые ошибки

<div class="grid">

<div class="card">
<span class="ico">⚠️</span>

### Забыл `#include`
Для строк нужен `#include <string>`.

</div>

<div class="card">
<span class="ico">⚠️</span>

### `cin` вместо `getline`
`cin >>` обрежет дело до первого пробела.

</div>

<div class="card">
<span class="ico">⚠️</span>

### `=` вместо `==`
Сравнение строк — это `==`, а не один `=`.

</div>

</div>

## Проверь себя · что выведет программа? 🧠

```cpp
std::string a = "Кот";
std::string b = "ёнок";
std::cout << (a + b).length();
```

### Подумай 10 секунд…

<div class="fact">Выведет <span class="out">7</span> — склеили «Котёнок», в нём семь букв.</div>

---

## Проверь себя · ещё раз 🧠

```cpp
std::string s = "нет";
if (s == "да") std::cout << "Иду";
else std::cout << "Остаюсь";
```

### Что выведет?

<div class="fact">Выведет <span class="out">Остаюсь</span> — строка `s` не равна «да», поэтому сработал `else`.</div>
