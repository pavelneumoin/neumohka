## `std::string` — строка текста

```cpp
#include <string>

std::string delo = "Сделать уроки";
```

### Строка хранит любой текст: слово, фразу, целое дело.

- Для строк нужен `#include <string>` вверху программы

---

## Длина строки: `.length()`

```cpp
std::string delo = "Уроки";
std::cout << delo.length();
```

### `.length()` говорит, **сколько символов** в строке.

> В слове «Уроки» пять букв — выведет **5**. Пробелы тоже считаются.

---

## Склейка строк: `+`

```cpp
std::string imya = "Аня";
std::cout << "Привет, " + imya + "!";
```

### Плюс `+` **склеивает** строки в одну.

> Получится **Привет, Аня!** — три кусочка соединились в одну фразу.

---

## Сравнение строк: `==`

```cpp
std::string otvet = "да";
if (otvet == "да") {
    std::cout << "Поехали!";
}
```

### Две строки сравнивают через `==` — точно так же, как числа.

> Важно: «да» и «Да» — **разные** строки. Большая буква имеет значение.

---

## Ввод одного слова: `std::cin`

```cpp
std::string slovo;
std::cin >> slovo;
```

### `std::cin >>` читает **одно слово** — до первого пробела.

> Если ввести «Сделать уроки», то в `slovo` попадёт только «Сделать». Это нам мешает!

---

## Ввод целой строки: `std::getline`

```cpp
std::string delo;
std::getline(std::cin, delo);
```

### `std::getline` читает **всю строку целиком** — вместе с пробелами.

> Теперь «Сделать уроки» попадёт в `delo` полностью. Это то, что нужно для дел.

---

## Список дел = `vector<string>`

```cpp
#include <vector>
#include <string>

std::vector<std::string> dela;
dela.push_back("Сделать уроки");
dela.push_back("Погулять");
```

### Список строк хранит сразу несколько дел — как журнал, только из текста.

---

## Выводим список дел

```cpp
for (int i = 0; i < dela.size(); i++) {
    std::cout << i + 1 << ". " << dela[i] << "\n";
}
```

### Перебираем список и печатаем дела с номерами.

> `i + 1` нужно, чтобы нумерация для человека шла с **1**, а не с 0.

---

## Проверь себя · что выведет программа? 🧠

```cpp
std::string a = "Кот";
std::string b = "ёнок";
std::cout << (a + b).length();
```

### Подумай 10 секунд…

> Выведет **7**. Склеили «Котёнок» — в нём семь букв.

---

## Проверь себя · ещё раз 🧠

```cpp
std::string s = "нет";
if (s == "да") std::cout << "Иду";
else std::cout << "Остаюсь";
```

### Что выведет?

> Выведет **Остаюсь** — строка `s` не равна «да», сработает `else`.
