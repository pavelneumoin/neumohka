## Зачем нужен список?

### Хранить 30 оценок в 30 переменных — это ужас.

```cpp
int o1 = 5, o2 = 4, o3 = 5; // а если их 30?!
```

<div class="fact">В телефоне твой список контактов — это тоже один большой список, а не сотня отдельных переменных. Так удобнее всем!</div>

## `std::vector<int>` — список чисел

```cpp
#include <vector>

std::vector<int> ocenki;
```

### Это пустой журнал оценок. В угловых скобках `<int>` — что внутри: целые числа.

<div class="tip">Не забудь <code>#include &lt;vector&gt;</code> вверху программы — иначе я не пойму, что такое список.</div>

---

## Добавляем оценки: `push_back`

```cpp
std::vector<int> ocenki;
ocenki.push_back(5);
ocenki.push_back(4);
ocenki.push_back(5);
```

### `push_back` кладёт новую оценку **в конец** списка.

<span class="out">в журнале: 5 4 5</span>

---

## Сколько оценок в списке? `.size()`

```cpp
std::cout << "Оценок: " << ocenki.size();
```

### `.size()` говорит, **сколько** элементов в списке.

<div class="fact">Положили 3 оценки — <span class="out">.size() = 3</span>. Очень пригодится для цикла!</div>

---

## Берём оценку по номеру

### У каждой оценки есть номер — **индекс**. Счёт идёт с нуля!

```cpp
std::cout << ocenki[0]; // первая оценка
std::cout << ocenki[1]; // вторая оценка
```

<div class="tip">Первый элемент всегда под номером <strong>0</strong>, а не 1. Это любимая ловушка новичков!</div>

---

## Перебираем список циклом `for`

```cpp
for (int i = 0; i < ocenki.size(); i++) {
    std::cout << ocenki[i] << " ";
}
```

### Цикл идёт от `0` до конца списка и печатает каждую оценку.

<div class="bubble"><img class="bip-head" src="../../assets/bip-head.svg"><span><code>i</code> — это номер ячейки, а <code>ocenki[i]</code> — сама оценка под этим номером. Я пройду по всему пеналу!</span></div>

---

## Разбираем перебор по строчкам

```cpp
for (int i = 0; i < ocenki.size(); i++) {
//       старт      пока не конец      дальше
    std::cout << ocenki[i] << " ";
}
```

- `i = 0` — начинаем с первой оценки
- `i < ocenki.size()` — пока не дошли до конца
- `ocenki[i]` — берём оценку под номером `i`

---

## Считаем средний балл

```cpp
int summa = 0;
for (int i = 0; i < ocenki.size(); i++) {
    summa += ocenki[i];
}
double sredniy = (double)summa / ocenki.size();
```

### Копим сумму всех оценок, потом делим на их количество.

<div class="fact"><code>(double)</code> нужен, чтобы средний балл вышел с дробной частью — например <span class="out">4.5</span>, а не просто 4.</div>

## Проверь себя · что выведет программа? 🧠

```cpp
std::vector<int> v;
v.push_back(7);
v.push_back(2);
std::cout << v.size() << " " << v[0];
```

### Подумай 10 секунд…

<div class="fact">Выведет <span class="out">2 7</span> — в списке два числа (`size` = 2), а первое (`v[0]`) — это 7.</div>

---

## Проверь себя · ещё раз 🧠

```cpp
std::vector<int> v;
v.push_back(3); v.push_back(3); v.push_back(3);
int s = 0;
for (int i = 0; i < v.size(); i++) s += v[i];
std::cout << s;
```

### Что выведет?

<div class="fact">Выведет <span class="out">9</span> — цикл сложил три тройки.</div>
