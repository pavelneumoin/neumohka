# Цикл for ⭐
</div>

## Как устроен for

Три части цикла записаны в одну строку:

```cpp
for (int i = 1; i <= 5; i++) {
    std::cout << i << " ";   // 1 2 3 4 5
}
```

- `int i = 1` — старт счётчика
- `i <= 5` — условие повтора
- `i++` — шаг (то же, что `i = i + 1`)

## Накопление суммы (копилка)

```cpp
int sum = 0;                 // копилку заводим ДО цикла
for (int i = 1; i <= 5; i++) {
    sum = sum + i;           // добавляем на каждом шаге
}
std::cout << sum;            // 15
```

## Запомни ✅

- `for` и `while` делают одно и то же — `for` короче
- `i++` = `i = i + 1`
- Копилку `sum = 0` заводи **до** цикла
- Хочешь больше повторов — меняй только число в условии

## Частые ошибки ⚠️

| Ошибка | Что будет |
|---|---|
| забыл `i++` | бесконечный цикл ♾️ |
| `int sum = 0;` внутри цикла | сумма сбрасывается |
| `for (...);` с `;` | пустое тело цикла |

## Словарик 📖

- **`for`** — цикл со счётчиком в одну строку
- **Диапазон** — числа от старта до конца (1…N)
- **`i++`** — увеличить счётчик на 1
- **Копилка (`sum`)** — переменная для накопления суммы
