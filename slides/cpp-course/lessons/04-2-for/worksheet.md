## 1 · Три части for

Соедини часть цикла `for (int i = 1; i <= 5; i++)` с тем, что она делает.

| Часть | | Что делает |
|---|---|---|
| `int i = 1` | ___ | **А** — шаг: увеличить счётчик |
| `i <= 5` | ___ | **Б** — старт счётчика |
| `i++` | ___ | **В** — условие повтора |

## 2 · Что выведет программа 🧠

Запиши, что появится на экране.

```cpp
for (int i = 1; i <= 4; i++) {
    std::cout << i * 2 << " ";
}
```

## 4 · Копилка сломалась — почини код 🔧

Эта программа всегда печатает не ту сумму. Найди ошибку и впиши исправление.

```cpp
for (int i = 1; i <= 5; i++) {
    int sum = 0;
    sum = sum + i;
}
std::cout << sum;
```
