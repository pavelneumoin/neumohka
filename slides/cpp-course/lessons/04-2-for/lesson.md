# Сегодня посчитаем звёзды и соберём <mark>сумму очков</mark> экспедиции.

## Вспомним прошлый урок

- Цикл `while` повторяет тело, пока верно условие
- У цикла есть счётчик: старт, условие, изменение
- Счётчик должен меняться — иначе бесконечный цикл

<div class="fact">Цикл <strong>for</strong> — это тот же цикл, но все три части записаны в одну строку.</div>

---

## while и for — это одно и то же

### В `while` три части цикла разбросаны. В `for` — собраны вместе.

<div class="cols">

<div>

**while**

```cpp
int i = 1;
while (i <= 5) {
    std::cout << i;
    i = i + 1;
}
```

</div>

<div>

**for**

```cpp
for (int i = 1; i <= 5; i++) {
    std::cout << i;
}
```

</div>

</div>

<div class="bubble"><img class="bip-head" src="../../assets/bip-head.svg"><span>Обе программы печатают одно и то же! Но for короче — все три части на одной строке.</span></div>

---

## Три части for

```cpp
for (int i = 1; i <= 5; i++) {
    std::cout << i << " ";
}
```

<div class="flow">

<div class="step">
<span class="ico">🏁</span>

**Старт** <small>int i = 1</small>

</div>

<div class="step">
<span class="ico">❓</span>

**Условие** <small>i &lt;= 5</small>

</div>

<div class="step">
<span class="ico">👣</span>

**Шаг** <small>i++</small>

</div>

</div>

<div class="tip"><strong>i++</strong> — это короткая запись для <strong>i = i + 1</strong>. Запомни этот значок.</div>

---

## Что такое `i++`

### `i++` означает «увеличь `i` на единицу». Самый частый шаг в `for`.

<div class="cols">

<div>

**Длинно**
`i = i + 1;`

</div>

<div>

**Коротко**
`i++`

</div>

</div>

<div class="fact">Обе записи делают одно и то же. В <strong>for</strong> почти всегда пишут i++ — так короче и привычнее.</div>

---

## Как for крутится · шаг за шагом

### Следим за `i` в `for (int i = 1; i <= 4; i++)`:

| Шаг | `i` | `i <= 4`? | Вывод |
|---|---|---|---|
| 1 | 1 | да | 1 |
| 2 | 2 | да | 2 |
| 3 | 3 | да | 3 |
| 4 | 4 | да | 4 |
| 5 | 5 | нет — стоп | — |

<div class="bubble"><img class="bip-head" src="../../assets/bip-head.svg"><span>Порядок такой: проверил условие, выполнил тело, сделал i++, снова проверил. И так по кругу.</span></div>

---

## Перебор диапазона 🌌

```cpp
for (int i = 1; i <= 10; i++) {
    std::cout << "Звезда №" << i << "\n";
}
```

### Один цикл — и программа сама пронумерует все 10 звёзд.

<div class="try">Хочешь до 100? Поменяй только <strong>10</strong> на <strong>100</strong>. Цикл не вырастет ни на строчку.</div>

---

## Накопление суммы · копилка 🐷

### Заводим «копилку» `sum = 0` и на каждом шаге добавляем в неё.

```cpp
int sum = 0;
for (int i = 1; i <= 5; i++) {
    sum = sum + i;
}
std::cout << "Очки: " << sum << "\n";
```

<div class="tip"><strong>sum = sum + i</strong> читается так: «возьми копилку, добавь в неё i, положи обратно».</div>

---

## Как растёт копилка · по шагам

### Считаем сумму `1 + 2 + 3 + 4 + 5`:

| Шаг | `i` | `sum` было | `sum` стало |
|---|---|---|---|
| 1 | 1 | 0 | 1 |
| 2 | 2 | 1 | 3 |
| 3 | 3 | 3 | 6 |
| 4 | 4 | 6 | 10 |
| 5 | 5 | 10 | 15 |

<div class="bubble"><img class="bip-head" src="../../assets/bip-head.svg"><span>В конце в копилке 15 — программа сложила все числа сама, а я даже не вспотел.</span></div>

---

## Частые ошибки ⚠️

<div class="grid">

<div class="card">
<span class="ico">♾️</span>

### Забыл `i++`
Без шага счётчик стоит на месте — бесконечный цикл.

</div>

<div class="card">
<span class="ico">🐷</span>

### Копилка внутри
`int sum = 0;` **внутри** цикла — обнуляется каждый шаг.

</div>

<div class="card">
<span class="ico">⚠️</span>

### Лишняя `;`
`for (...);` — тело отвалилось, цикл пустой.

</div>

</div>

<div class="tip">Копилку <strong>sum = 0</strong> заводи до цикла, иначе сумма всё время сбрасывается в ноль.</div>

---

## Проверь себя · что выведет программа? 🧠

```cpp
for (int i = 1; i <= 3; i++) {
    std::cout << i * 2 << " ";
}
```

### Подумай 10 секунд…

<div class="fact">Выведет <span class="out">2 4 6</span>. Для i = 1, 2, 3 печатается i, умноженное на 2: то есть 2, 4 и 6.</div>

---

## Проверь себя · копилка 🧠

```cpp
int sum = 0;
for (int i = 1; i <= 3; i++) {
    sum = sum + i;
}
std::cout << sum;
```

### Что окажется в копилке?

<div class="fact">Выведет <span class="out">6</span>. Копилка собрала 1 плюс 2 плюс 3 — получилось 6.</div>
