# Когда заранее знаешь, <mark>сколько раз</mark> повторить — выбирай `for`.

---

## Вспомним прошлый урок

- Цикл `while` повторяет тело, пока верно условие
- У цикла есть счётчик: старт, условие, изменение
- Счётчик должен меняться — иначе бесконечный цикл

> `for` — это тот же цикл, но все три части записаны **в одну строку**.

---

## План урока

1. Чем `for` удобнее `while`
2. Три части `for` в одной строке
3. Перебор диапазона: от 1 до N
4. Накопление суммы — копилка очков
5. **Практика в классе** — звёзды и очки полёта
6. **Домашнее задание**

---

## while и for — это одно и то же

### В `while` три части цикла разбросаны. В `for` — собраны вместе.

<div class="cols">

<div>

**while**

```cpp
int i = 1;
while (i <= 5) {
    std::cout << i;
    i = i + 1;
}
```

</div>

<div>

**for**

```cpp
for (int i = 1; i <= 5; i++) {
    std::cout << i;
}
```

</div>

</div>

Делают одно и то же. `for` короче — три части в одной строке.

---

## Три части for

```cpp
for (int i = 1; i <= 5; i++) {
    std::cout << i << " ";
}
```

- `int i = 1` — **старт**: с чего начать счётчик
- `i <= 5` — **условие**: пока повторяем
- `i++` — **шаг**: увеличить счётчик на 1

> `i++` — это короткая запись для `i = i + 1`.

---

## Что такое `i++`

### `i++` означает «увеличь `i` на единицу». Самый частый шаг в `for`.

<div class="cols">

<div>

**Длинно**
`i = i + 1;`

</div>

<div>

**Коротко**
`i++`

</div>

</div>

> Обе записи делают одно и то же. В `for` почти всегда пишут `i++`.

---

## Как for крутится · шаг за шагом

### Следим за `i` в `for (int i = 1; i <= 4; i++)`:

| Шаг | `i` | `i <= 4`? | Вывод |
|---|---|---|---|
| 1 | 1 | да | 1 |
| 2 | 2 | да | 2 |
| 3 | 3 | да | 3 |
| 4 | 4 | да | 4 |
| 5 | 5 | нет — стоп | — |

> Порядок: проверили условие → выполнили тело → сделали `i++` → снова проверили.

---

## Перебор диапазона

```cpp
for (int i = 1; i <= 10; i++) {
    std::cout << "Звезда №" << i << "\n";
}
```

### Один цикл — и программа сама пронумерует все 10 звёзд.

> Хочешь до 100? Поменяй только `10` на `100`. Цикл не вырастет ни на строчку.

---

## Накопление суммы · копилка

### Заводим «копилку» `sum = 0` и на каждом шаге добавляем в неё.

```cpp
int sum = 0;
for (int i = 1; i <= 5; i++) {
    sum = sum + i;
}
std::cout << "Очки: " << sum << "\n";
```

> `sum = sum + i` — «возьми копилку, добавь `i`, положи обратно».

---

## Как растёт копилка · по шагам

### Считаем сумму `1 + 2 + 3 + 4 + 5`:

| Шаг | `i` | `sum` было | `sum` стало |
|---|---|---|---|
| 1 | 1 | 0 | 1 |
| 2 | 2 | 1 | 3 |
| 3 | 3 | 3 | 6 |
| 4 | 4 | 6 | 10 |
| 5 | 5 | 10 | 15 |

> В конце `sum = 15` — программа сложила все числа сама.

---

## Частые ошибки

<div class="grid">

<div class="card">
<span class="ico">♾️</span>

### Забыл `i++`
Без шага счётчик стоит на месте — бесконечный цикл.

</div>

<div class="card">
<span class="ico">⚠️</span>

### Копилка внутри
`int sum = 0;` **внутри** цикла — обнуляется каждый шаг.

</div>

<div class="card">
<span class="ico">⚠️</span>

### Лишняя `;`
`for (...);` — тело отвалилось, цикл пустой.

</div>

</div>

> Копилку `sum = 0` заводи **до** цикла, иначе сумма всё время сбрасывается.

---

## Проверь себя · что выведет программа? 🧠

```cpp
for (int i = 1; i <= 3; i++) {
    std::cout << i * 2 << " ";
}
```

### Подумай 10 секунд…

> Выведет **2 4 6**. Для `i = 1, 2, 3` печатается `i * 2`: то есть 2, 4 и 6.

---

## Проверь себя · копилка 🧠

```cpp
int sum = 0;
for (int i = 1; i <= 3; i++) {
    sum = sum + i;
}
std::cout << sum;
```

### Что окажется в копилке?

> Выведет **6**. Копилка собрала `1 + 2 + 3 = 6`.
