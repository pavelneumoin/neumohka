## 1 · Какой нужен тип

Магазин хранит разные данные. Выбери подходящий тип (впиши букву).

| Данные | | Тип |
|---|---|---|
| Цена `60` (целое) | ___ | **А** — `double` |
| Цена `49.90` (с копейками) | ___ | **Б** — `std::string` |
| Название «Молоко» | ___ | **В** — `int` |

## 2 · Что выведет программа

Напиши, что появится на экране.

```cpp
std::string name = "Сыр";
int price = 250;
std::cout << name << " — " << price << " руб.";
```
