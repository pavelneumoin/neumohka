## Что такое переменная?

### Представь подписанный ящик на складе магазина.

<div class="bubble"><img class="bip-head" src="../../assets/bip-head.svg"><span>На ящике написано имя — например, price. Внутри лежит значение — число 50. Заглянул внутрь — увидел, что там. Это и есть переменная!</span></div>

## Магазину нужны разные ящики

### Цена — это число. Название товара — это текст. Они разные!

<div class="cols">

<div>

**Число**
цена `50`, количество `3`

</div>

<div>

**Текст**
название «Молоко», имя покупателя

</div>

</div>

<div class="tip">Поэтому у каждого ящика есть <strong>тип</strong> — он говорит, что именно можно туда положить. В ящик для чисел текст не влезет.</div>

---

## Главные типы данных

<div class="grid">

<div class="card">
<span class="ico">🔢</span>

### int
Целое число: `50`, `3`, `-7`

</div>

<div class="card">
<span class="ico">💵</span>

### double
Дробное число: `49.90`, `3.5`

</div>

<div class="card">
<span class="ico">🏷️</span>

### std::string
Текст: `"Молоко"`, `"Аня"`

</div>

</div>

<div class="fact">Ещё есть <strong>char</strong> — один символ (буква, цифра), и <strong>bool</strong> — «да/нет». С ними познакомимся в конце урока.</div>

---

## Объявляем переменную

```cpp
int price = 50;
```

### Читаем слева направо: тип, имя, знак `=`, значение.

- `int` — тип (целое число)
- `price` — имя ящика
- `= 50` — кладём внутрь значение `50`

<div class="try">Заведи ящик <strong>int count = 3;</strong> — это будет количество товаров. Скоро мы его выведем!</div>

---

## Выводим значение на экран

```cpp
int price = 50;
std::cout << "Цена: " << price << " руб.\n";
```

### Без кавычек `price` — это **ящик**, и я выведу его содержимое.

<div class="fact">На экране появится <span class="out">Цена: 50 руб.</span> Текст я печатаю в кавычках, а имя ящика — без.</div>

---

## Кавычки решают всё!

<div class="cols">

<div>

**С кавычками**

```cpp
std::cout << "price";
```
выведет слово **price**

</div>

<div>

**Без кавычек**

```cpp
std::cout << price;
```
выведет **число из ящика**

</div>

</div>

<div class="bubble"><img class="bip-head" src="../../assets/bip-head.svg"><span>«price» в кавычках — это буквы, я их просто читаю вслух. А price без кавычек — это ящик, я загляну внутрь и скажу, что там.</span></div>

---

## Дробные цены: тип double

```cpp
double price = 49.90;
std::cout << "Цена: " << price << " руб.\n";
```

### Для копеек нужен `double` — он хранит число с точкой.

<div class="tip">Дробная часть пишется через <strong>точку</strong>, а не запятую: 49.90, а не 49,90. Я понимаю только точку!</div>

---

## Текст и буквы: string и char

```cpp
std::string name = "Молоко";
char size = 'M';
std::cout << name << " размер " << size << "\n";
```

- `std::string` — текст, в **двойных** кавычках `"..."`
- `char` — один символ, в **одинарных** кавычках `'...'`

<div class="fact">Один символ — это как одна клавиша. На экране будет <span class="out">Молоко размер M</span></div>

---

## Да или нет: тип bool

```cpp
bool inStock = true;
std::cout << "Есть на складе: " << inStock << "\n";
```

### `bool` хранит только `true` (да) или `false` (нет).

<div class="fact">Я выведу <span class="out">Есть на складе: 1</span> — единицу для true и ноль для false. Так компьютер показывает «да» и «нет». Кстати, телефон тоже думает нулями и единицами!</div>

---

## Соберём ценник целиком

```cpp
std::string name = "Хлеб";
int price = 35;
std::cout << name << " — " << price << " руб.\n";
```

### Завели ящик с названием, ящик с ценой — и вывели оба.

<div class="fact">На экране: <span class="out">Хлеб — 35 руб.</span> Готовый ценник из двух переменных!</div>

</div>

<div class="card">
<span class="ico">⚠️</span>

### Запятая в double
`49,90` неверно — нужна **точка** `49.90`.

</div>

</div>

## Проверь себя · что я выведу? 🧠

```cpp
int apples = 4;
std::cout << "apples" << " = " << apples;
```

### Подумай 10 секунд…

<div class="fact">Я выведу <span class="out">apples = 4</span> Слово apples в кавычках — буквы, а apples без кавычек — значение из ящика, то есть 4.</div>

---

## Проверь себя · ещё разок 🧠

```cpp
double price = 19.5;
std::cout << price << " руб.";
```

### Что появится на экране?

<div class="fact">Появится <span class="out">19.5 руб.</span> — double хранит дробное число, а точка отделяет копейки.</div>
