# Заводим переменные 🏷️
</div>

## Что такое переменная

Переменная — «ящик с именем», где лежит одно значение:

```cpp
int price = 50;   // тип  имя  =  значение
```

## Главные типы

| Тип | Что хранит | Пример |
|---|---|---|
| `int` | целое число | `60` |
| `double` | дробное число | `49.90` |
| `std::string` | текст | `"Молоко"` |
| `char` | один символ | `'M'` |
| `bool` | да / нет | `true` |

## Объявление и вывод

```cpp
std::string name = "Хлеб";
int price = 35;
std::cout << name << " — " << price << " руб.\n";
```

## Запомни ✅

- Текст пишем в кавычках, имя ящика — **без** кавычек
- `char` — в **одинарных** кавычках: `'M'`
- Дробь в `double` — через **точку**: `49.90`
- В конце команды — точка с запятой `;`

## Частые ошибки ⚠️

| Ошибка | Как правильно |
|---|---|
| `price = 50;` | `int price = 50;` |
| `int price = "50";` | `int price = 50;` |
| `double p = 49,90;` | `double p = 49.90;` |
| `std::cout << "price";` | `std::cout << price;` |

## Словарик 📖

- **Переменная** — ящик с именем для одного значения
- **Тип** — что можно хранить в ящике (число, текст…)
- **Присваивание** — кладём значение в ящик знаком `=`
