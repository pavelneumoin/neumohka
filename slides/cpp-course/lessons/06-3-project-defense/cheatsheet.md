## План выступления 📋

1. **Идея** — что делает программа (одно предложение)
2. **Как устроена** — какие темы курса использовал
3. **Что было трудно** — какую ошибку победил
4. **Чем горжусь** — самая классная часть

## Перед показом ✅

- Запусти программу заранее — вдруг не собирается
- Выбери **один** интересный кусочек кода для показа
- Продумай, что будешь вводить во время демонстрации
- Уложись в 2–3 минуты

## Критерии хорошего проекта 🏆

- **Работает** — запускается без ошибок
- **Понятно** — объясняет пользователю, что делать
- **Доведён до конца** — план выполнен
- **Своя идея** — придумал сам

## Что показать в коде

```cpp
for (int i = 0; i < 5; i = i + 1) {
    std::cout << questions[i] << "\n";
    std::cin >> answer;
    if (answer == correct[i]) score = score + 1;
}
```

Покажи «сердце» программы и поясни простыми словами.
