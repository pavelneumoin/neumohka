## Тип `bool` — да или нет

```cpp
bool alive = true;     // правда, да
bool gameOver = false; // ложь, нет
```

`bool` хранит всего два значения: `true` и `false`.

## Знаки сравнения

```cpp
score > 50    // больше?
score < 50    // меньше?
score >= 50   // больше или равно?
score <= 50   // меньше или равно?
score == 50   // равно? (два знака =)
score != 50   // не равно?
```

Каждое сравнение даёт `true` или `false`.

## Вывод результата

```cpp
std::cout << (score >= 100);
```

`cout` печатает `bool` как **1** (true) или **0** (false).

## Запомни ✅

- Сравнение — это вопрос, ответ всегда `true`/`false`
- `>=` и `<=` пишутся слитно, без пробела
- `==` сравнивает, а один `=` присваивает

## Частые ошибки ⚠️

| Ошибка | Как правильно |
|---|---|
| `score = 100` (сравнение) | `score == 100` |
| `score > = 100` | `score >= 100` |
| ждём `true` в выводе | выведется `1` или `0` |

## Словарик 📖

- **`bool`** — тип «да/нет», хранит `true` или `false`
- **`true` / `false`** — правда / ложь
- **`==`** — «равно ли?» (вопрос)
- **`!=`** — «не равно ли?»
