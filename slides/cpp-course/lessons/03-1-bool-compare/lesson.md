## Тип `bool` — да или нет

### Есть числа (`int`), есть текст. А теперь — ответ на вопрос.

```cpp
bool alive = true;
bool gameOver = false;
```

<div class="fact">Тип <strong>bool</strong> хранит всего два значения: true (правда, да) и false (ложь, нет). Как выключатель: включён или выключен.</div>

---

## Сравнение даёт `bool`

### Когда мы сравниваем два числа, получается `true` или `false`.

```cpp
int score = 90;
bool win = score > 50;
```

<div class="bubble"><img class="bip-head" src="../../assets/bip-head.svg"><span>Я читаю <strong>score &gt; 50</strong> как вопрос: «очков больше пятидесяти?». Их 90 — значит true. Этот ответ и запомнит переменная win.</span></div>

---

## Знаки сравнения

| Знак | Вопрос | Пример | Ответ |
|---|---|---|---|
| `>` | больше? | `90 > 50` | true |
| `<` | меньше? | `90 < 50` | false |
| `>=` | больше или равно? | `50 >= 50` | true |
| `<=` | меньше или равно? | `40 <= 50` | true |

<div class="tip">Знаки <strong>&gt;=</strong> и <strong>&lt;=</strong> пишутся двумя символами подряд, без пробела между ними.</div>

---

## Равно и не равно

### Для «равно» в C++ — **два** знака равно `==`.

```cpp
int lives = 3;
bool last = lives == 1;   // ровно одна жизнь?
bool more = lives != 0;   // жизни ещё есть?
```

- `==` — «равно ли?» (это вопрос, а не присваивание!)
- `!=` — «не равно ли?» (знак `!` читается «не»)

---

## Очень важно: `=` и `==` — разное

<div class="cols">

<div>

**`=` — присвоить**
`score = 100;`
положить 100 в `score`

</div>

<div>

**`==` — сравнить**
`score == 100;`
спросить: равно ли 100?

</div>

</div>

<div class="tip">Один знак <strong>=</strong> кладёт значение в переменную. Два знака <strong>==</strong> спрашивают, равны ли числа. Перепутаешь — игра решит не то!</div>

## Как увидеть результат

### `std::cout` умеет печатать и `bool` — но числами.

```cpp
int coins = 80;
std::cout << (coins >= 100);
```

<div class="bubble"><img class="bip-head" src="../../assets/bip-head.svg"><span>Я печатаю bool так: <span class="out">0</span> — это false, <span class="out">1</span> — это true. Монет 80, до 100 не хватает — выведу 0.</span></div>

---

## Разбор примера · проверка уровня

```cpp
int score = 70;
int needed = 50;
bool open = score >= needed;
std::cout << "Уровень открыт: " << open;
```

На экране: <span class="out">Уровень открыт: 1</span>

<div class="fact">Очков 70, нужно 50. Вопрос «70 больше или равно 50?» — правда. Единица означает «да, открыт».</div>

## Частые ошибки

<div class="grid">

<div class="card">
<span class="ico">⚠️</span>

### `=` вместо `==`
`score = 100` присвоит, а не сравнит. Сравнение — всегда `==`.

</div>

<div class="card">
<span class="ico">⚠️</span>

### Пробел в `> =`
Надо `>=`, слитно. С пробелом я не пойму.

</div>

<div class="card">
<span class="ico">⚠️</span>

### Ждём «true» в выводе
`cout` печатает `bool` как `1` или `0`, а не словами.

</div>

</div>
