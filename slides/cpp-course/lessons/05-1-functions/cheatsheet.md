# Помощники-функции 🧑‍🏫
</div>

## Функция, которая что-то делает

```cpp
void privet(std::string imya) {
    std::cout << "Привет, " << imya << "!\n";
}
```

`void` — функция действует, но **ничего не возвращает**. В скобках — параметры.

## Функция, которая возвращает ответ

```cpp
int ploshad(int a, int b) {
    return a * b;
}
```

Перед именем — тип ответа (`int`). `return` отдаёт результат наружу.

## Как позвать функцию

```cpp
privet("Аня");                 // просто выполнить
int s = ploshad(4, 3);         // сохранить ответ
std::cout << ploshad(2, 5);    // сразу вывести
```

## Запомни ✅

- Функцию пишем **выше** `main`
- Вызов — это имя со скобками `()`
- Параметры передают данные внутрь функции
- Функция с типом `int` обязана сделать `return`

## Частые ошибки ⚠️

| Ошибка | Как правильно |
|---|---|
| `privet;` | `privet();` |
| `ploshad 4, 3` | `ploshad(4, 3)` |
| функция с `int` без `return` | добавь `return ...;` |

## Словарик 📖

- **Функция** — помощник, который выполняет свой кусок кода
- **Параметр** — данные, которые передаём функции в скобках
- **`return`** — возвращает ответ из функции
- **`void`** — функция ничего не возвращает
