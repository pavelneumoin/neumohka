## Зачем вообще нужны функции?

### Представь: надо поздороваться с Аней, Борей и Викой.

```cpp
std::cout << "Привет, Аня!\n";
std::cout << "Привет, Боря!\n";
std::cout << "Привет, Вика!\n";
```

<div class="fact">Код почти одинаковый — меняется только имя. Когда копируешь строки <strong>раз за разом</strong> — пора звать помощника.</div>

## Объявляем своего помощника

```cpp
void pozdorovatsya() {
    std::cout << "Привет, класс!\n";
}
```

### Это помощник по имени `pozdorovatsya`. Внутри `{ }` — что он делает.

<div class="tip"><strong>void</strong> значит «помощник ничего не возвращает» — просто действует.</div>

---

## Как позвать помощника

```cpp
int main() {
    pozdorovatsya();
    pozdorovatsya();
    return 0;
}
```

### Имя со скобками `()` — это **вызов**. Позвали дважды — поздоровались дважды.

<div class="try">Допиши третий вызов `pozdorovatsya();` — пусть Бип поздоровается трижды.</div>

---

## Разбираем по строчкам

```cpp
void pozdorovatsya() {        // объявили помощника
    std::cout << "Привет!\n"; // что он делает
}
int main() {                  // главная функция
    pozdorovatsya();          // зовём помощника
}
```

<div class="tip">Функцию пиши <strong>выше</strong> <code>main</code> — чтобы <code>main</code> уже знал про помощника.</div>

---

## Параметры — данные для помощника

### А если здороваться **по имени**? Передадим имя в скобках.

```cpp
void privet(std::string imya) {
    std::cout << "Привет, " << imya << "!\n";
}
```

<div class="bubble"><img class="bip-head" src="../../assets/bip-head.svg"><span><code>std::string imya</code> в скобках — это <strong>параметр</strong>. При вызове ты кладёшь туда нужное имя, а я подставляю его в работу.</span></div>

---

## `return` — помощник возвращает ответ

### Функция умеет не только действовать, но и **посчитать и вернуть** результат.

```cpp
int ploshad(int a, int b) {
    return a * b;
}
```

<div class="tip">Вместо <strong>void</strong> пишем тип ответа — здесь <strong>int</strong>. А <code>return</code> отдаёт результат обратно тому, кто звал.</div>

---

## Используем ответ функции

```cpp
int main() {
    int s = ploshad(4, 3);
    std::cout << "Площадь: " << s;
    return 0;
}
```

### Помощник посчитал `4 * 3`, вернул **12** — мы сохранили его в `s`.

<span class="out">Площадь: 12</span>

---

## Частые ошибки

<div class="grid">

<div class="card">
<span class="ico">⚠️</span>

### Забыл `()`
`privet` без скобок — это не вызов. Пиши `privet();`.

</div>

<div class="card">
<span class="ico">⚠️</span>

### Забыл `return`
Функция с типом `int` **обязана** вернуть число.

</div>

<div class="card">
<span class="ico">⚠️</span>

### Помощник ниже `main`
`main` не знает про него. Пиши функцию **выше**.

</div>

</div>

---

## Проверь себя · что выведет программа? 🧠

```cpp
int dvazhdy(int x) {
    return x + x;
}
int main() {
    std::cout << dvazhdy(5);
}
```

### Подумай 10 секунд…

<div class="fact">Выведет <span class="out">10</span> — помощник взял <code>x = 5</code> и вернул <code>5 + 5</code>.</div>

---

## Проверь себя · ещё раз 🧠

```cpp
void krik(std::string s) {
    std::cout << s << "!!!";
}
int main() {
    krik("Ура");
}
```

### Что появится на экране?

<div class="fact">Выведет <span class="out">Ура!!!</span> — помощник добавил три восклицательных знака к слову.</div>
