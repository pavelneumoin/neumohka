# Придумываем свой проект 🛠️
</div>

## Идеи для проекта 💡

- **Викторина** — вопросы и счётчик очков
- **Касса** — считает покупки и сдачу
- **Предсказания** — случайная фраза
- **Текстовая игра** — приключение с выбором
- **Угадай число** — компьютер загадал, ты угадываешь

## Шаблон плана 📋

1. Поздороваться и объяснить правила
2. Сделать самый главный шаг (один вопрос / одну покупку)
3. Добавить переменную-счётчик или сумму
4. Повторить с помощью цикла
5. Показать результат в конце

## Кирпичики из курса

```cpp
int score = 0;                 // счётчик
std::cin >> answer;            // спросить
if (answer == "Париж") { }     // проверить
for (int i = 0; i < 3; i++) {} // повторить
std::vector<std::string> list; // список
```

## Правило одного шага ✅

- Сделал шаг → запустил → работает → берись за следующий
- Бери **маленькую** идею, но доделай до конца
- Сначала чтобы работало, красота — потом

## Словарик 📖

- **Проект** — своя программа от идеи до запуска
- **План** — список маленьких шагов
- **Шаг** — кусочек, который легко написать и проверить
