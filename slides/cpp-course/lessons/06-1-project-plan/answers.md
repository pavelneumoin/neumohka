# Придумываем свой проект 🛠️ ✅
</div>

<div class="note"><strong>Версия для учителя.</strong> Ориентиры и образцы к рабочему листу 6.1. Задания модуля 6 часто творческие — это примеры «как может быть», а не единственно верный ответ.</div>

## 1 · Выбери идею

Любой выбор верный. Главное — чтобы ученик мог объяснить одной фразой, что делает программа.

<div class="solution">Образец: <strong>Моя программа — игра-викторина: задаёт три вопроса по математике и в конце показывает, сколько очков набрал игрок.</strong> На что смотреть: идея посильная (не «3D-игра»), укладывается в изученное — переменные, ввод, if, цикл, может быть vector.</div>

## 2 · Разрежь на шаги

Хороший план — 4–6 шагов, каждый шаг — одно маленькое действие.

<div class="solution">Образец для викторины: 1) поздороваться и объяснить правила; 2) задать первый вопрос и прочитать ответ; 3) сравнить ответ с правильным и прибавить очко; 4) повторить для остальных вопросов; 5) показать итог. Критерий: шаги идут по порядку и каждый можно проверить отдельно.</div>

## 3 · Что понадобится

<div class="solution">Образец таблицы. Шаг «задать вопрос и прочитать ответ» — переменные и cin. Шаг «сравнить и прибавить очко» — if/else. Шаг «повторить для всех вопросов» — цикл (while или for), можно vector со списком вопросов. Главное: ученик связал шаг с конкретной темой курса.</div>

## 4 · Первый шаг проекта

Образец первого шага (приветствие и первый вопрос):

```cpp
#include <iostream>
#include <string>

int main() {
    int score = 0;
    std::cout << "Привет! Это викторина. Отвечай числом.\n";

    int answer = 0;
    std::cout << "Сколько будет 2 + 2? ";
    std::cin >> answer;
    if (answer == 4) {
        score = score + 1;
        std::cout << "Верно!\n";
    } else {
        std::cout << "Не угадал.\n";
    }

    std::cout << "Очки: " << score << "\n";
    return 0;
}
```

<div class="solution">Принимается любой рабочий первый шаг: он должен компилироваться и делать что-то осмысленное. На код-стиль не придираемся, важна работоспособность.</div>

## 5 · Самый трудный шаг

<div class="solution">Образец: <strong>Труднее всего — повторять вопросы циклом, чтобы не писать одинаковый код много раз. Идея: сложить вопросы и ответы в два vector и пройти по ним циклом for.</strong> Критерий: ученик честно назвал затруднение и предложил хотя бы одну реалистичную идею.</div>

## 6 · Придумай свою идею ★

<div class="solution">Образец: <strong>Игра «Угадай число»: программа загадывает число от 1 до 10, а игрок угадывает.</strong> Три шага: 1) загадать число (rand); 2) спросить догадку и сравнить (больше/меньше); 3) повторять, пока не угадал. Критерий: идея новая (нет в списке), описана понятно, разбита ровно на 3 шага.</div>
