## Идея 5 · Угадай число 🎲

```cpp
int secret = 1 + std::rand() % 100;
int guess;
std::cout << "Угадай число от 1 до 100: ";
std::cin >> guess;
if (guess == secret) std::cout << "Точно!";
```

<div class="try">Узнал знакомую игру из модуля 4? Возьми её за основу — половина проекта уже у тебя в голове.</div>

## Как выглядит викторина внутри

```cpp
int score = 0;
std::string answer;
std::cout << "Столица Франции? ";
std::cin >> answer;
if (answer == "Париж") {
    score = score + 1;
}
std::cout << "Очков: " << score;
```

### Всё знакомо: `cin`, `if`, счётчик-`score`. Осталось добавить ещё вопросов.

## Как касса считает покупки

```cpp
double total = 0;
double price;
for (int i = 0; i < 3; i = i + 1) {
    std::cout << "Цена товара: ";
    std::cin >> price;
    total = total + price;
}
std::cout << "Итого: " << total << " руб.";
```

### Цикл + переменная-сумма — и касса готова считать чек.

## Правило одного шага ✅

### Сделал шаг → запустил → работает → берёшься за следующий.

<div class="tip">Не пиши сразу всю программу. Один работающий кусочек надёжнее, чем <strong>десять недописанных</strong>. Это как собирать конструктор: деталь за деталью.</div>

<img class="hero-bot" src="../../assets/bip.svg">

<!-- _class: task -->

# Задача 1 · Выбери идею 💡

Выбери **одну** идею для своего проекта: викторина, касса, предсказания, текстовая игра или «угадай число».

- Запиши её в одно предложение: «Моя программа будет…»
- Подумай, кто и зачем будет ей пользоваться

`Время: 5 минут`

---

<!-- _class: task -->

# Задача 2 · Разрежь на шаги ✂️

Разбей свой проект на **4–6 маленьких шагов** — как в примере с викториной.

<div class="try">Начни прямо сейчас: запиши первый шаг. Почти всегда это «поздороваться и объяснить правила» — самый лёгкий старт.</div>

`Время: 7 минут`

---

<!-- _class: task -->

# Задача 3 · Что нам понадобится 🧰

Напротив каждого шага напиши, **какие знания** из курса нужны.

- Например: «счётчик очков → переменная `int`»
- «выбор пути → `if` / `else`», «список → `vector`»

`Время: 7 минут`

---

<!-- _class: task -->

# Задача 4 · Самый первый шаг 🚀 <span class="pill">★ со звёздочкой</span>

Возьми **первый шаг** из своего плана и напиши для него маленькую программу прямо сейчас.

1. Только первый шаг, не весь проект
2. Запусти и проверь, что он работает

`Кто запустит первый кусочек — покажет классу!`
