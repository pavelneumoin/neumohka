## Что такое проект?

### Проект — это твоя собственная программа от идеи до запуска.

> Раньше мы решали готовые задачи. Теперь **ты решаешь, что делать**: придумываешь идею, рисуешь план и собираешь по шагам.

Главный секрет: большой проект = много маленьких знакомых кусочков.

## Идея 5 · Угадай число 🎲

```cpp
int secret = 1 + std::rand() % 100;
int guess;
std::cout << "Угадай число от 1 до 100: ";
std::cin >> guess;
if (guess == secret) std::cout << "Точно!";
```

### Знакомая игра из модуля 4 — отличная база для проекта.

---

## Как выглядит викторина внутри

```cpp
int score = 0;
std::string answer;
std::cout << "Столица Франции? ";
std::cin >> answer;
if (answer == "Париж") {
    score = score + 1;
}
std::cout << "Очков: " << score;
```

> Всё уже знакомо: `cin`, `if`, переменная-счётчик. Осталось добавить ещё вопросов.

## Как касса считает покупки

```cpp
double total = 0;
double price;
for (int i = 0; i < 3; i = i + 1) {
    std::cout << "Цена товара: ";
    std::cin >> price;
    total = total + price;
}
std::cout << "Итого: " << total << " руб.";
```

### Цикл + переменная-сумма — и касса готова считать чек.

## Разбиваем задачу на шаги

### Возьмём викторину. Разрежем её на маленькие дела:

1. Поздороваться и объяснить правила
2. Задать **один** вопрос и проверить ответ
3. Добавить счётчик правильных ответов
4. Добавить ещё 2–3 вопроса
5. В конце показать результат

> Каждый шаг — маленькая программа, которую легко проверить.

---

## Правило одного шага ✅

### Сделал шаг → запустил → работает → берёшься за следующий.

> Не пиши сразу всю программу. Один работающий кусочек надёжнее, чем десять недописанных.

Это как собирать конструктор: деталь за деталью.

<!-- _class: task -->

# Задача 1 · Выбери идею 💡

Выбери **одну** идею для своего проекта: викторина, касса, предсказания, текстовая игра или «угадай число».

- Запиши её в одно предложение: «Моя программа будет…»
- Подумай, кто и зачем будет ей пользоваться

`Время: 5 минут`

---

<!-- _class: task -->

# Задача 2 · Разрежь на шаги ✂️

Разбей свой проект на **4–6 маленьких шагов** — как в примере с викториной.

- Пиши шаги по порядку, от простого к сложному
- Каждый шаг должен быть маленьким и проверяемым

`Подсказка: первый шаг — почти всегда «поздороваться и объяснить правила»`

---

<!-- _class: task -->

# Задача 3 · Что нам понадобится 🧰

Напротив каждого шага напиши, **какие знания** из курса нужны.

- Например: «счётчик очков → переменная `int`»
- «выбор пути → `if` / `else`», «список → `vector`»

`Время: 7 минут`

---

<!-- _class: task -->

# Задача 4 · Самый первый шаг 🚀 <span class="pill">★ со звёздочкой</span>

Возьми **первый шаг** из своего плана и напиши для него маленькую программу прямо сейчас.

1. Только первый шаг, не весь проект
2. Запусти и проверь, что он работает

`Кто запустит первый кусочек — покажет классу!`

---

## Что мы сегодня научились 💪

- Проект — это своя программа от идеи до запуска
- Хороший план = идея + список маленьких шагов
- Большая задача собирается из знакомых кусочков
- Правило: один шаг → запустил → работает → дальше
- Лучше маленький, но доделанный проект
