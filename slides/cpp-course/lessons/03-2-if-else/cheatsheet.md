# Игра принимает решения 🎮
</div>

## `if` — «если»

```cpp
if (score >= 50) {
    std::cout << "Пройден!";
}
```

Если условие — правда, выполняется код в `{ }`.

## `if / else` — развилка

```cpp
if (hp > 0) {
    std::cout << "Жив";
} else {
    std::cout << "Конец игры";
}
```

Выполнится **ровно одна** ветка.

## `else if` — много вариантов

```cpp
if (p >= 85) {
    std::cout << "Отлично";
} else if (p >= 60) {
    std::cout << "Норм";
} else {
    std::cout << "Подтянись";
}
```

Условия проверяются **сверху вниз**, берётся первое подходящее.

## Запомни ✅

- После `if (...)` точку с запятой **не** ставим
- Условие — в круглых скобках `( )`, код — в фигурных `{ }`
- Сравнение — всегда через `==`

## Частые ошибки ⚠️

| Ошибка | Как правильно |
|---|---|
| `if (x = 5)` | `if (x == 5)` |
| `if (x > 0);` | `if (x > 0) { ... }` |
| `if x > 0 { }` | `if (x > 0) { }` |

## Словарик 📖

- **`if`** — «если»: выполнить код при условии-правде
- **`else`** — «иначе»: что делать, если ложь
- **`else if`** — ещё один вариант проверки
- **ветка** — один из путей программы
