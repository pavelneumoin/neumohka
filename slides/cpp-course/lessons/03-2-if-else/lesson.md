# Теперь программа сама решает, <mark>что делать дальше</mark>.

### Хватило очков — «Победа!». Не хватило — «Попробуй ещё». Это умеет `if`.

---

## Вспомним прошлый урок

- `bool` хранит `true` или `false`
- Сравнения: `>`, `<`, `>=`, `<=`, `==`, `!=`
- Сравнение даёт ответ «да/нет»

> Сегодня по этому ответу программа будет **выбирать**, что вывести.

---

## План урока

1. Команда `if` — «если…»
2. Скобки и фигурные скобки
3. `else` — «а иначе…»
4. `else if` — несколько вариантов
5. **Практика в классе** — ветвления в игре
6. **Домашнее задание**

## Команда `if` — «если»

### Если условие — правда, выполнить код в фигурных скобках.

```cpp
int score = 90;
if (score >= 50) {
    std::cout << "Уровень пройден!";
}
```

> Очков 90, `90 >= 50` — правда, поэтому программа напечатает «Уровень пройден!». Если бы было меньше 50 — промолчала бы.

---

## Из чего состоит `if`

```cpp
if (условие) {
    // что сделать, если правда
}
```

- После `if` — **условие в круглых скобках** `( )`
- Дальше — **фигурные скобки** `{ }` с командами
- Внутри обычно сравнение из прошлого урока

> После `if (...)` точку с запятой **не ставим** — за ней идут `{ }`.

---

## `else` — «а иначе»

### `if` решает что делать, когда правда. `else` — когда ложь.

```cpp
int hp = 0;
if (hp > 0) {
    std::cout << "Герой жив";
} else {
    std::cout << "Игра окончена";
}
```

> Здоровья 0, `hp > 0` — ложь, поэтому выполнится ветка `else`: «Игра окончена».

---

## Развилка на дороге 🛣️

### `if/else` — это развилка: программа идёт по одной из двух дорог.

<div class="cols">

<div>

**Условие — правда**
идём в `if { }`

</div>

<div>

**Условие — ложь**
идём в `else { }`

</div>

</div>

> Выполнится **ровно одна** ветка — никогда обе сразу.

---

## `else if` — много вариантов

### Когда вариантов больше двух, добавляем `else if`.

```cpp
int score = 75;
if (score >= 90) {
    std::cout << "Оценка 5";
} else if (score >= 70) {
    std::cout << "Оценка 4";
} else {
    std::cout << "Учись ещё";
}
```

---

## Как читается `else if`

### Программа проверяет условия **сверху вниз** и выбирает первое подходящее.

1. `score >= 90`? — нет (75 < 90)
2. `score >= 70`? — да! → «Оценка 4»
3. остальное не проверяется

> Как только нашли подходящую ветку — дальше программа не смотрит.

---

## Worked example · вход по возрасту

```cpp
int age = 12;
if (age >= 12) {
    std::cout << "Можно играть!";
} else {
    std::cout << "Игра 12+";
}
```

> Возраст 12, `12 >= 12` — правда. Выполнится первая ветка: «Можно играть!». Граница `>=` включает само число 12.

---

## Частые ошибки

<div class="grid">

<div class="card">
<span class="ico">⚠️</span>

### `=` вместо `==`
`if (x = 5)` — это присваивание! Сравнение — `if (x == 5)`.

</div>

<div class="card">
<span class="ico">⚠️</span>

### `;` сразу после `if`
`if (x > 0);` — условие ни на что не влияет. Точку с запятой убрать.

</div>

<div class="card">
<span class="ico">⚠️</span>

### Забыли `{ }`
Без скобок в `if` попадёт только одна строка. Лучше всегда ставить `{ }`.

</div>

</div>

## Проверь себя · что выведет программа? 🧠

```cpp
int coins = 40;
if (coins >= 100) {
    std::cout << "Купил меч";
} else {
    std::cout << "Мало монет";
}
```

### Подумай 10 секунд…

> Монет 40, `40 >= 100` — ложь. Выполнится `else`: программа напечатает **Мало монет**.

---

## Проверь себя · ещё разок 🧠

```cpp
int level = 3;
if (level == 1) {
    std::cout << "Старт";
} else if (level == 3) {
    std::cout << "Босс!";
}
```

### Подумай 10 секунд…

> Уровень 3. Первое условие ложно, второе — `3 == 3` — правда. Выведет **Босс!**
