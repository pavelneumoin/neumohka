## 1 · Три части цикла

Соедини часть цикла с тем, что она делает (впиши букву справа).

| Часть | | Что делает |
|---|---|---|
| `int n = 5;` | ___ | **А** — повторяем, пока оно верно |
| `while (n > 0)` | ___ | **Б** — стартовое значение счётчика |
| `n = n - 1;` | ___ | **В** — двигает счётчик к выходу |

## 2 · Что выведет программа 🧠

Запиши, что появится на экране.

```cpp
int n = 4;
while (n > 0) {
    std::cout << n << " ";
    n = n - 1;
}
```
