# Цикл while 🚀
</div>

## Как устроен while

Цикл повторяет тело, **пока** условие верно:

```cpp
int n = 5;            // 1. старт счётчика
while (n > 0) {       // 2. условие повтора
    std::cout << n;   // 3. тело — что повторяем
    n = n - 1;        // 4. шаг счётчика
}
```

## Считаем вниз и вверх

```cpp
int n = 5;
while (n > 0) { n = n - 1; }   // 5,4,3,2,1

int k = 1;
while (k <= 5) { k = k + 1; }  // 1,2,3,4,5
```

`n = n - 1` — уменьшить счётчик. `k = k + 1` — увеличить.

## Запомни ✅

- У цикла три части: **старт**, **условие**, **изменение** счётчика
- Счётчик обязательно должен **меняться** на каждом шаге
- Когда условие стало ложным — цикл останавливается
- Тело цикла — внутри фигурных скобок `{ }`

## Частые ошибки ⚠️

| Ошибка | Что будет |
|---|---|
| забыл `n = n - 1;` | бесконечный цикл ♾️ |
| `while (n > 0);` | пустое тело, цикл «сломан» |
| `n >= 0` вместо `n > 0` | лишний шаг (ещё и `0`) |

## Словарик 📖

- **Цикл** — повтор команд по условию
- **`while`** — «пока верно условие — повторяй»
- **Счётчик** — переменная, считающая шаги цикла
- **Бесконечный цикл** — цикл, который не может остановиться
