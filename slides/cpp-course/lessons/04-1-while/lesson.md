## Проблема ста строк 😩

### Нужен обратный отсчёт от 5 до 1. Писать так?

```cpp
std::cout << 5 << "\n";

```

## Цикл — это повтор по условию

### Робот-космонавт повторяет одно действие, пока выполняется условие.

<div class="cols">

<div>

**Пока** ракета не взлетела —
продолжай отсчёт. ⏳

</div>

<div>

Условие стало ложным —
повтор прекращается. 🛑

</div>

</div>

<div class="fact">Цикл <strong>while</strong> переводится как «пока». Читай его так: «пока верно условие, повторяй тело».</div>

---

## Как выглядит while

```cpp
int n = 5;
while (n > 0) {
    std::cout << n << "\n";
    n = n - 1;
}
```

<div class="bubble"><img class="bip-head" src="../../assets/bip-head.svg"><span>Читай по-человечески: пока <strong>n больше нуля</strong> — печатай n и уменьшай его на 1. Я повторю это, пока n не дойдёт до нуля.</span></div>

---

## Разбираем по строчкам

```cpp
int n = 5;            // счётчик: с чего начинаем
while (n > 0) {       // условие: пока верно — повторяем
    std::cout << n;   // тело: что повторяем
    n = n - 1;        // меняем счётчик — шаг к выходу
}
```

### У любого цикла три части: старт счётчика, условие и его изменение.

---

## Что такое счётчик 🔢

### Счётчик — обычная переменная, которая считает шаги цикла.

<div class="flow">

<div class="step">
<span class="ico">🏁</span>

**Старт** <small>int n = 5</small>

</div>

<div class="step">
<span class="ico">❓</span>

**Условие** <small>n > 0?</small>

</div>

<div class="step">
<span class="ico">👣</span>

**Шаг** <small>n = n - 1</small>

</div>

</div>

<div class="tip"><strong>n = n - 1</strong> означает «возьми старое n, отними 1, положи обратно». Так счётчик движется к выходу.</div>

---

## Как цикл крутится по шагам

### Следим за `n` (начали с `n = 5`):

| Шаг | `n` | `n > 0`? | Что вывело |
|---|---|---|---|
| 1 | 5 | да | 5 |
| 2 | 4 | да | 4 |
| 3 | 3 | да | 3 |
| 4 | 2 | да | 2 |
| 5 | 1 | да | 1 |
| 6 | 0 | нет — стоп | — |

<div class="bubble"><img class="bip-head" src="../../assets/bip-head.svg"><span>Когда n стало 0, условие n &gt; 0 — ложь. Я выхожу из цикла.</span></div>

---

## Считать можно и вверх 📈

### Здесь счётчик **растёт**: `n = n + 1`, а условие — `n <= 3`.

```cpp
int n = 1;
while (n <= 3) {
    std::cout << "Ступень " << n << " готова\n";
    n = n + 1;
}
```

<div class="tip">Счётчик должен двигаться к тому, чтобы условие стало ложным.</div>

---

## Частые ошибки ⚠️

<div class="grid">

<div class="card">
<span class="ico">♾️</span>

### Бесконечный цикл
Забыл `n = n - 1` — счётчик не меняется, цикл крутится вечно.

</div>

<div class="card">
<span class="ico">⚠️</span>

### Лишняя `;`
`while (n > 0);` — тело отвалилось, цикл «пустой».

</div>

<div class="card">
<span class="ico">🔀</span>

### Не тот знак
`n > 0` и `n >= 0` дают **разное** число повторов.

</div>

</div>

<div class="tip">Главная ловушка — <strong>бесконечный цикл</strong>. Всегда проверяй: счётчик точно меняется и движется к выходу?</div>

---

## Проверь себя · что выведет программа? 🧠

```cpp
int n = 3;
while (n > 0) {
    std::cout << n << " ";
    n = n - 1;
}
```

### Подумай 10 секунд…

<div class="fact">Выведет <span class="out">3 2 1</span>. На шаге, где n стало 0, условие n больше нуля ложно — цикл остановился.</div>

---

## Проверь себя · ещё разок 🧠

```cpp
int n = 1;
while (n <= 4) {
    std::cout << n << " ";
    n = n + 1;
}
```

### Что появится на экране?

<div class="fact">Появится <span class="out">1 2 3 4</span>. Счётчик растёт от 1, а на n = 5 условие n меньше либо равно 4 становится ложным.</div>
