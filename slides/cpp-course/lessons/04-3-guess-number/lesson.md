## Случайное число 🎲

```cpp
#include <cstdlib>

int secret = rand() % 100;   // число от 0 до 99
```

### `rand()` выдаёт случайное число, а `% 100` оставляет остаток от 0 до 99.

<div class="tip">Знак <strong>%</strong> — это деление с остатком из второго модуля. Остаток деления на 100 всегда меньше 100.</div>

---

## Чтобы числа были разными 🔀

### `srand(time(0))` пишут **один раз** в начале `main` — он заводит генератор по часам.

```cpp
#include <cstdlib>
#include <ctime>
srand(time(0));              // один раз в начале
int secret = rand() % 100;
```

<div class="bubble"><img class="bip-head" src="../../assets/bip-head.svg"><span>Без srand я каждый запуск загадываю одно и то же число — скучно! С ним — каждый раз новое.</span></div>

---

## break · выйти из цикла 🛑

### `break` досрочно прерывает цикл — как стоп-кран.

```cpp
while (true) {
    std::cin >> guess;
    if (guess == secret) break;  // выходим
}
```

<div class="tip">Как только число угадано, <strong>break</strong> мгновенно выводит нас из цикла — дальше тело не выполняется.</div>

---

## continue · пропустить шаг ⏭️

### `continue` пропускает остаток шага и переходит к следующему повтору.

```cpp
for (int i = 1; i <= 5; i++) {
    if (i == 3) continue;   // тройку пропускаем
    std::cout << i << " ";
}
```

<div class="fact">Выведет <span class="out">1 2 4 5</span> — на шаге i равно 3 тело пропустилось, а цикл пошёл дальше.</div>

---

## Игра целиком · часть 1/2 🧩

### Сначала загадываем число и готовим переменные:

```cpp
#include <iostream>
#include <cstdlib>
#include <ctime>
int main() {
    srand(time(0));
    int secret = rand() % 100, guess;
```

Три `#include`: iostream — ввод-вывод, cstdlib — rand, ctime — time.

---

## Игра целиком · часть 2/2 🧩

### Теперь сам цикл угадывания. Соедини часть 1 и часть 2 — и играй:

```cpp
    while (true) {
        std::cin >> guess;
        if (guess < secret) std::cout << "Больше!\n";
        else if (guess > secret) std::cout << "Меньше!\n";
        else { std::cout << "Угадал!\n"; break; }
    }
    return 0;
}
```

---

## Разбираем главное

```cpp
while (true) {            // цикл «пока не угадаем»
    std::cin >> guess;    // игрок вводит число
    if (...) ...          // подсказка больше/меньше
    else { ...; break; }  // угадал — выходим
}
```

<div class="tip"><strong>while (true)</strong> крутится вечно — выйти из него можно только через <strong>break</strong>. Поэтому break тут обязателен, иначе игра не закончится.</div>
