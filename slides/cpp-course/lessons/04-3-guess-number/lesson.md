## Случайное число

```cpp
#include <cstdlib>

int secret = rand() % 100;   // число от 0 до 99
```

### `rand()` выдаёт случайное число, а `% 100` оставляет остаток 0–99.

> `% 100` — это деление с остатком из модуля 2. Остаток всегда меньше 100.

---

## Чтобы числа были разными

```cpp
#include <cstdlib>
#include <ctime>

srand(time(0));              // «перемешать» один раз в начале
int secret = rand() % 100;
```

### `srand(time(0))` запускают **один раз** в начале `main` — по часам.

> Без него `rand()` каждый запуск выдаёт одно и то же число. С ним — каждый раз новое.

---

## break · выйти из цикла

### `break` досрочно прерывает цикл — как стоп-кран.

```cpp
while (true) {
    std::cin >> guess;
    if (guess == secret) break;  // выходим
}
```

> Как только число угадано — `break` мгновенно выводит нас из цикла.

---

## continue · пропустить шаг

### `continue` пропускает остаток шага и переходит к следующему повтору.

```cpp
for (int i = 1; i <= 5; i++) {
    if (i == 3) continue;   // тройку пропускаем
    std::cout << i << " ";
}
```

> Выведет **1 2 4 5** — на шаге `i == 3` тело пропустилось, цикл пошёл дальше.

---

## break и continue · в чём разница

</div>

> `break` — стоп всему циклу. `continue` — «этот шаг пропустим, дальше работаем».

---

## Собираем игру · по шагам

### Логика игры на пальцах:

1. Компьютер загадал `secret`
2. Игрок вводит число `guess`
3. Если `guess < secret` — «Больше!»
4. Если `guess > secret` — «Меньше!»
5. Если равны — «Угадал!» и `break`

> Повторяем шаги 2–5 в цикле, пока не угадали.

---

## Игра «Угадай число» целиком

```cpp
srand(time(0));
int secret = rand() % 100;
int guess;
while (true) {
    std::cin >> guess;
    if (guess < secret) std::cout << "Больше!\n";
    else if (guess > secret) std::cout << "Меньше!\n";
    else { std::cout << "Угадал!\n"; break; }
}
```

### Это вся игра! Нужны три `#include`.

---

## Разбираем главное

```cpp
while (true) {            // цикл «пока не угадаем»
    std::cin >> guess;    // игрок вводит число
    if (...) ...          // подсказка больше/меньше
    else { ...; break; }  // угадал — выходим
}
```

### `while (true)` крутится вечно — выйти из него можно только через `break`.

> Поэтому `break` тут обязателен: без него игра никогда не закончится.

## Проверь себя · что выведет программа? 🧠

```cpp
for (int i = 1; i <= 5; i++) {
    if (i == 2) continue;
    std::cout << i << " ";
}
```

### Подумай 10 секунд…

> Выведет **1 3 4 5**. На шаге `i == 2` сработал `continue` — двойку пропустили.

---

## Проверь себя · break 🧠

```cpp
for (int i = 1; i <= 5; i++) {
    if (i == 3) break;
    std::cout << i << " ";
}
```

### А здесь что появится?

> Выведет **1 2**. На `i == 3` сработал `break` — цикл сразу остановился.
