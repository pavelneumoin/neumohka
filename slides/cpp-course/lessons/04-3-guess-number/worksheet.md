## 1 · Кто за что отвечает

Соедини команду с тем, что она делает (впиши букву справа).

| Команда | | Что делает |
|---|---|---|
| `rand() % 100` | ___ | **А** — выйти из цикла досрочно |
| `break` | ___ | **Б** — случайное число 0–99 |
| `continue` | ___ | **В** — пропустить один шаг цикла |

## 2 · Что выведет программа 🧠

Запиши, что появится на экране.

```cpp
for (int i = 1; i <= 5; i++) {
    if (i == 3) continue;
    std::cout << i << " ";
}
```

## 4 · Игра сломалась — почини код 🔧

Эта игра **никогда не заканчивается**, даже когда число угадано. Найди, чего не хватает, и впиши строку.

```cpp
while (true) {
    std::cin >> guess;
    if (guess == secret) {
        std::cout << "Угадал!\n";
    }
}
```
