---

## Зачем именно C++?

> На C++ написаны игры, браузеры, операционные системы и даже Марс-роверы.

- **Скорость** — один из самых быстрых языков в мире
- **Фундамент** — поймёшь, как устроен компьютер изнутри
- **Перенос** — после C++ любой другой язык даётся легко
- **Олимпиады и ЕГЭ** — отличная база для информатики

## Твоя первая программа

```cpp
#include <iostream>

int main() {
    std::cout << "Привет, мир!";
    return 0;
}
```

### Запускаешь — и компьютер здоровается с тобой. 🎉

---

## Разбираем по строчкам

```cpp
#include <iostream>   // подключаем ввод-вывод
int main() {          // главная функция — точка старта
    std::cout << "Привет!";  // печатаем текст на экран
    return 0;         // программа завершилась успешно
}
```

- `#include` — берём готовые инструменты
- `main()` — отсюда программа начинает работу
- `std::cout <<` — «вывести на экран»

---

## Переменные — коробки для данных

```cpp
int age = 14;
double price = 99.5;
std::string name = "Аня";
```

### Каждая переменная хранит одно значение, и его можно менять.

> Имя коробки придумываешь ты. Тип (`int`, `double`...) говорит, что внутри.

---

## Основные типы данных

| Тип | Что хранит | Пример |
|---|---|---|
| `int` | целые числа | `42`, `-7` |
| `double` | дробные числа | `3.14` |
| `char` | один символ | `'A'` |
| `bool` | да / нет | `true` |
| `string` | текст | `"Привет"` |

---

## Ввод и вывод

```cpp
int year;
std::cout << "Введи год: ";
std::cin  >> year;
std::cout << "Тебе будет " << 2026 - year;
```

- `cout <<` — **вывести** на экран
- `cin >>` — **прочитать** то, что ввёл пользователь

### Программа начинает общаться с человеком.

---

## Условия: программа принимает решения

```cpp
if (score >= 50) {
    std::cout << "Зачёт сдан!";
} else {
    std::cout << "Нужно подготовиться";
}
```

### `if` проверяет условие — и выбирает, что делать дальше.

---

## Циклы: повторяем без копипасты

```cpp
for (int i = 1; i <= 5; i++) {
    std::cout << i << " ";
}
// выведет: 1 2 3 4 5
```

> Вместо того чтобы писать одно и то же 100 раз, мы говорим: «повтори 100 раз».
