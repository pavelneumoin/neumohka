# Неумошка

Библиотека готовых уроков математики и информатики Павла Неумоина:
презентации, рабочие листы, умный поиск, избранное и личный кабинет.

## Что в репозитории

| Папка / файл | Что |
|---|---|
| [`RDP.md`](RDP.md), [`design-prompt.md`](design-prompt.md) | Исторические документы ранней концепции |
| [`web/`](web/) | Архивный HTML-прототип; не является текущим сайтом |
| [`web-next/`](web-next/) | **Текущий Next.js 16 + React 19 сайт**: 62 урока, защищённые PDF, поиск, карусель, логин и кабинет |
| [`deploy/`](deploy/) | Production-конфигурация и инструкция выкладки `web-next` |

## Запустить локально

Боевой стек:

```bash
cd web-next
npm install            # уже сделано
npm run dev            # http://localhost:3000
```

Старый прототип (только как референс):

```bash
cd web
python -m http.server 8000
# → http://localhost:8000/
```

Полная проверка и production-запуск:

```bash
cd web-next
npm run check
npm run test:data
npm run test:search
npm run test:auth-core
npm run build
npm run start
npm run test:smoke     # в другом терминале
```

Инструкция выкладки: [`deploy/DEPLOY.md`](deploy/DEPLOY.md).
